# 受限扫描证明与只读查询链检查点

计划 scan-path-20261023；S2 尚未验收，进度 15%。本轮未执行查询基准、提交或推送。

完成镜像在实验 15/41 配置下可经完整语义扫描后只读打开。BUILDING、直接创建及可写打开在前置边界拒绝；默认 5/31 与兼容 13/39 不授予扫描证明。证明绑定存储服务、IO、完整根、描述符和 IO 写入纪元；新完整校验不继承旧作用域权限。

持久成员目录供给现有批入口，批次只复制最多 512 个选定 ID。只有同步字段读取作用域可省略已覆盖的主实体与竞争 ROW 路由检查；实体种类、成员活性、字段 owner/slot/type/CRC 检查仍保留。作用域退出、嵌套、取消与异常恢复原检查，不能把临时证明写进普通认证缓存。源通过调用者预付 128 KiB，再由有限子账户细分；字段回退与消费者恢复原查询账户，总源读取上限仍为 1 MiB。

测试覆盖真实名称目录、重复/缺失标签、整数、文本、复杂值、缺失值、批外 ID、根/IO 变化、嵌套、句柄移动、损坏但 CRC 有效的标签，以及真实查询引擎过滤/分组/owning 输出。58 项隔离模块用例通过；默认与兼容配置的最终结果和精确构建/链接命令见 receipt.json。全部是必要模块测试，没有执行全量单元测试。

保留首轮失败日志：命名空间/私有 API 测试调用、调用者账户缺失、观察计数断言、span 夹具初始化、缺失值断言及 QueryEngine 独立链接漏掉 ANTLR。修正后以新鲜对象与核心库重跑。一次默认测试过滤器误拼导致 0 用例，不计入验收；最终明确运行实际模块用例。

限制：尚未实现完整成员更新与恢复、超过 64 标签的通用回退、真实两库的整文件空间/资源验收及最终性能比较。该证明不授权完成发布、空间豁免或默认生产采用。旧检查点只证明各自源码版本。
