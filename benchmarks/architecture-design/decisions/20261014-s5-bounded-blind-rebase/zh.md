# S5.1 有界冲突验证与最新根重建

原生事务增加有界 Node 属性盲写替换路径：读取或 Vector 快照从未暴露，最终态为 1–64 个持久 Node 属性 owner，且无 patch、创建/删除、标签、Edge 变更或创建身份计划。其他路径保持全图 fence；即使只获取而未使用读取快照，也永久选择保守路径，不接受不完整读集合、不回放查询/过程回调。

符合条件时保留一个认证原始基础 pin。固定 64 项栈数组保存可缺失的 Property Directory 位置依赖，并验证 Node 存活。已有 `(PageId, slot, slot_generation)` 将 owner 版本与共享页代际分离：同页另一 owner 更新不必使本 owner 失效，值修改后恢复仍推进槽代际。迁移可以保守冲突，没有新增持久 epoch 或格式。暴露快照的缺失读取仍走全图 fence，不宣称通用点读/谓词依赖追踪。

发布门内每次尝试验证最新元数据，再由普通执行器从最新根和共享页构建、维护/验证当前索引及约束。旧私有页不能覆盖相邻 owner，最终发布仍检查当前全图 fence。最多构建三次，每次重验，耗尽为终止冲突。暴露读取、提交、回滚及失败均释放基础 pin。相交 owner 更新/删除产生终止冲突，最新唯一约束失败保持确定回滚，不确定持久提交保持重开隔离。

214 项相关邻接、完整性、原生事务/故障、隔离及绑定读取测试通过。新增六种历史：真实同页两个盲写并发成功且重开保留双方结果；更新/删除/缺失变存在；暴露读取后保守拒绝；暂存后新增 DDL 与最新唯一冲突；修改后恢复原值的 owner 代际；超过 64 项时保守拒绝且不丢依赖。20 个新建同页并发历史也通过。旧保守同页/竞争测试显式暴露读取，保留原读依赖合同。未运行全量单测或性能基准。

接受 S5.1 的初始有界生产协议与保守回退，不宣称更细粒度实体读取、谓词 epoch、Edge/标签操作、跨 owner 发布或全局资源所有权完成。S5.3–S5.5 及最终性能仍待推进。
