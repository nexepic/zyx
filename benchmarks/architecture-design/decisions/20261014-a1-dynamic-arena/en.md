# A1 PMR dynamic-value arena foundations

Date: 2026-10-14. Status: an isolated task-local dynamic-value owner passes verification. Production sources/consumers, owning output adapters, and complete batch envelopes remain unintegrated. Accepted progress stays 6/34 (17.6%); no new complete item means no automatic commit/push.

DynamicValueArena owns six PMR buffers through BudgetMemoryResource and a shared local MaterializedByteBudget: value descriptors, contiguous bytes, list child indices, map entries (key-byte range/value index), three-component TemporalDuration values, and forest root indices. Fixed bool/int64/double/date/datetime use uint64 bits and C++20 bit_cast. Duration preserves three int64 components. String/bytes tags and missing/NULL/value states remain distinct. Ranges/indices are uint64, constrained by platform size_t and allocator capacity; no input PropertyValue buffers are retained.

DynamicValueId carries uint64 index/owner/incarnation. Every type/state/scalar/text/binary/child/map-entry access authenticates owner/incarnation and descriptor bounds. Foreign, reconstructed-at-the-same-address, reused-version, and out-of-range descriptors fail. Append attempts, including preflight/allocation/guard failure, appendMissing, and clear/release invalidate old handles/raw borrows. Published indices stay stable and callers can explicitly reacquire current handles. Returned string_view/span values remain lifetime-bound C++ borrows; stale pointers cannot be automatically authenticated.

The append adapter performs guarded preflight against whole-arena value/byte/list-child/map-entry limits and a depth bound of 1–256. It reserves each actual PMR buffer with old/new overlap charged, then copies text/binary/keys in guarded 4096-byte chunks and copies nested descriptors. A root returns only after full copying and the final guard. Copy/allocation/cancellation failure restores all six published lengths. Successfully reserved capacity remains live and charged. clear reuses it; release/destruction refunds it. Traversal is not a second evaluator: no comparison/function execution or arithmetic/NULL/order-contract change.

Lists preserve order and duplicate positions. Maps capture the input map's current iteration order, without claiming validation of every keys()/map-output function. Owning PropertyValue/QueryResult reconstruction remains pending. Empty string/bytes/list/map are valid and byte/child/map-entry quotas may be zero. NULL and missing remain distinct. UNKNOWN/COMPOSITE are not ordinary current PropertyValue query variants and are not forced into the arena. Input heaps remain caller-owned/charged. Preflight plus copying is an explicit migration cost, not a native-decoder zero-copy or complete source-admission claim.

Fourteen new tests cover fixed/temporal types, int64 extremes, negative zero/NaN payload/infinity, embedded-NUL strings/binary, ownership after input destruction, nested maps/lists/NULL/durations, missing/NULL, clear/release, address reuse/foreign/out-of-range IDs, preallocation work-limit rejection, each observed upstream allocation failure, and every preflight/copy/byte-chunk/final-guard failure with preserved prefixes and retained-capacity accounting. Two independently locally budgeted arenas also use committed CoordinatedMemoryResource upstreams: the shared process cap rejects the second, preserves ResourceAdmissionDenied, permits retry after releasing the first, and ultimately refunds every level to zero. This proves component composition, not Database-wide integration.

Dynamic arena plus FixedWidthBatch/Column selected modules passed **40 tests/3 suites** (14 new, 26 existing), with no new compile warnings. Linux/C++20 only; no full suite, performance benchmark, or Kuzu comparison. Production behavior is unchanged; native source columns still own PropertyValue. This does not complete S2.1–S2.5. Baseline is pushed commit 47f886ad. Program/layout/query-snapshot envelopes, rectangular multicolumn batches, allocation-admitting native producers/dynamic consumers, and final owning output are next; do not force redundant whole-column copies merely to claim integration.
