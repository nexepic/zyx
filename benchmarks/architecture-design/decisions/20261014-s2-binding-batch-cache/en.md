# S2.1 execution binding, batches and cache identity

## Delivered boundary

The frontend and logical IR remain authoritative. Authenticated native read snapshots now construct a query-local `BoundExecutionProgram` before visiting operators. The sealed program owns charged input/output names, scope-specific slot IDs, operator membership and topology. Cloned IR and descriptors from another program are rejected. Correlated CALL imports are explicit; aliases and identically spelled variables in separate scopes have separate identities. Compiler limits bound operators, slots, name bytes and depth; cycles, invalid children, cancellation and admission failure abort before execution. The caller-owned logical AST outlives this query-local program. Executable programs are never cached.

Native scalar filter, project and generic aggregate consumers build expression descriptors once per operator, gather row inputs at the boundary and read numeric input ordinals inside the existing evaluator. Property descriptors own keys and validate database, format, catalog/page-directory observations and token capability; unknown tokens retain name lookup semantics. Property reads still call the existing validated named read surface: token resolution does not imply a new token-only storage kernel. Parameters have a separate owner namespace, reference the current immutable QueryContext and defer missing-parameter errors until the active branch. Strings/lists/maps/bytes returned from parameters use the preadmitted owning-copy path. Local comprehensions, quantifiers, pattern expressions and other scope adapters keep the existing semantic evaluator; they do not accidentally bind a shadowed name to an outer slot.

## Unified batch publication

`BatchEnvelope` is a rectangular, charged metadata owner over fixed integer/double/bool columns, snapshot-bound EntityRef columns, bounded dynamic-value forests and primitive numeric columns. It records a fresh program identity, sealed column layout, exact data snapshot, source owners/incarnations, selection and source-local original ordinals. Selection preserves duplicates and order. A cell distinguishes missing, NULL and value where the producer preserves that information. Node and Edge identity spaces remain separate, including self-loops and deferred Edge endpoints.

All sources must use the same materialized-byte budget. Publication validates every cell before downstream effects; temporary and previous metadata overlap is charged. Failed publication preserves the prior complete prefix but invalidates old handles. Cancellation and each upstream metadata-allocation failure refund temporary admission. Source mutation, batch reuse, layout/program mismatch, foreign budgets or a different snapshot invalidate borrows. Borrowed cells and raw views expire with their owner or mutation; public results continue to own their values independently of database close and snapshot release. Layout, source owners and snapshot must outlive the envelope.

Native direct Node numeric aggregation now publishes and consumes this envelope before accumulator updates. Metadata pressure explicitly declines the optional envelope; the previously charged numeric/scalar path remains responsible for correctness. Primitive input bridges expose `exact_presence=false` because the legacy property-value producer merges missing and NULL. Presence-sensitive consumers must retain the owning/master semantic adapter. This prevents treating an erased presence bit as exact information.

## Cache identity and capability boundary

PlanCache stores cloned, unbound logical IR only. Physical/executable-plan caching remains disabled: no parameter values, slots, resolved tokens, borrowed batches or page pointers survive a query. Native backends expose a bounded metadata-only cache witness using the same database/format/catalog/page-directory observation as execution binding. QueryEngine checks it before using a cached plan and around compilation; another engine's schema publication, database/format changes or capability loss clear the cache. Publication during compilation prevents caching that compilation under a newer witness. Metadata observation occurs outside the PlanCache mutex and opens no logical graph snapshot. EXPLAIN is never inserted into this cache and remains execution-snapshot-free. Database ephemeral reset clears the cache and witness.

The witness is deliberately conservative: data COW may change the page directory and invalidate logical IR. A persistent independent schema epoch and cross-query physical cache are later work, not implied by this acceptance. Cache `hits()` remains the existing LRU lookup statistic; an identity-invalidated lookup can be counted even though execution recompiles. QueryEngine retains its existing per-client concurrency contract.

Readers without authenticated schema identity retain the explicit charged semantic row adapter. They are not silently granted native binding or cached physical capabilities. Native caller-injected input/mutation refresh paths and operators not migrated here also retain the charged adapter. Existing IR child/output-vector APIs can allocate before their capacity is measured; this change does not claim process-global preadmission of compiler IR allocations. A6/S5 closes that broader resource boundary.

## Acceptance scope

S2.1 accepts the implemented binding, batch publication and cache identity boundary, including a real native consumer. It does not accept S2.2's complete scan/filter/project/aggregate migration, S2.3's remaining operators and mutation read sides, S2.4's entire semantics matrix or S2.5 performance comparisons. Dynamic arena production, factorized graph results, physical algorithm/pipeline selection, global resource coordination and spill remain pending in their original items. No on-disk format or isolation promise changes. Final performance gates remain in the user's final optimization window.
