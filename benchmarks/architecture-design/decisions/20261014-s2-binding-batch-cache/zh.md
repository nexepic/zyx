# S2.1 执行绑定、批次与缓存身份

## 已交付边界

保留前端及逻辑 IR。具有可信 schema 身份的原生读快照在访问算子前构建查询局部 `BoundExecutionProgram`，封存输入/输出名称、作用域 slot、算子成员关系和拓扑，并对这些内存计费。克隆 IR、其他程序的描述符不能复用。关联 CALL 显式传入导入变量；别名与不同作用域中的同名变量具有不同身份。算子数、slot 数、名称字节和深度有界；环、无效子节点、取消和预算失败在执行前报错。调用者持有的逻辑 AST 必须活到执行结束；可执行程序不进入缓存。

原生标量 filter、project 和通用 aggregate 消费者按算子构建表达式描述符，在行边界收集输入，随后在原有求值器中按数字序号读取。属性描述符持有键名，校验数据库、格式、catalog/page-directory 观察值及 token 能力；未知 token 保留名称查找语义。实际属性读取继续使用已有的受校验名称接口，不能宣称已实现 token 专用存储内核。参数使用独立 owner 命名空间，引用本次不可变 QueryContext，缺失参数仅在分支实际求值时报错。参数中的字符串、列表、map、bytes 使用预准入的拥有式复制路径。局部推导、量词、模式等作用域继续使用语义适配器，避免把遮蔽变量误绑到外层。

## 统一批次发布

`BatchEnvelope` 为定宽整数/浮点/布尔列、绑定快照的 EntityRef 列、有界动态值森林和数值列提供矩形、计费的元数据 owner。记录新鲜程序身份、封存列布局、精确数据快照、源 owner/incarnation、selection 和源内原始序号。selection 保留重复及顺序。生产者支持时分别表示 missing、NULL 和值。Node/Edge 身份空间保持分离，包括自环和延迟解析的 Edge 端点。

所有源使用同一个物化字节预算。下游产生效果前校验每个单元；新旧元数据重叠占用也计费。发布失败保留上次完整前缀，但旧句柄失效。取消及每个上游元数据分配失败均退还临时准入。源修改、批次复用、跨布局/程序/预算/快照借用被拒绝。单元视图不能越过 owner 生命周期或修改；公开结果继续独立拥有数据，可在数据库关闭和快照释放后读取。布局、源 owner 和快照必须比封装活得更久。

原生直接 Node 数值聚合在更新 accumulator 前发布并消费该封装。元数据预算不足时显式退出可选封装，沿用已计费的数值/标量路径。旧属性值生产者合并 missing 和 NULL，因此数值桥接明确标记 `exact_presence=false`；依赖存在性的消费者必须继续使用主数据/拥有式语义适配器，不能把丢失的 presence 当作精确信息。

## 缓存身份与能力边界

PlanCache 只保存克隆的未绑定逻辑 IR。物理/可执行计划缓存仍关闭，参数值、slot、解析 token、借用批次和页指针不跨查询保存。原生后端提供有界的纯元数据缓存身份，与执行绑定使用相同的数据库、格式和 catalog/page-directory 观察值。QueryEngine 在使用缓存及编译前后检查；其他引擎发布 schema、数据库/格式变化或能力丢失会清缓存。编译期间发生发布时，不会把旧优化观察值盖上新的身份存入缓存。元数据读取位于 PlanCache 锁外，不打开逻辑图快照。EXPLAIN 不写入缓存，继续不创建执行快照。数据库临时状态重置同时清除缓存及身份。

该身份刻意保守：数据 COW 改变 page directory 也可能清除逻辑缓存。独立持久 schema epoch 和跨查询物理缓存仍是后续工作。`hits()` 保持已有 LRU 查找统计，身份失效后重编译的查找也可能被计入。QueryEngine 保留原有每客户端的并发使用约定。

没有可信 schema 身份的 reader 沿用显式计费的语义行适配器，不自动获得原生绑定或物理缓存能力。调用者注入输入、变更读侧刷新及未迁移算子也保留计费适配器。现有 IR 子节点/输出向量接口可能先分配再测容量；本项不宣称已完成编译 IR 的进程级预准入，完整资源边界由 A6/S5 后续闭合。

## 验收范围

S2.1 验收实际绑定、批次发布和缓存身份边界，包含真实原生消费者。S2.2 的完整 scan/filter/project/aggregate 迁移、S2.3 其他算子及变更读侧、S2.4 完整语义矩阵、S2.5 性能对比不在本项验收范围。动态 arena 原生生产者、因子化图中间结果、物理算法/流水线选择、全局资源协调和 spill 仍由原任务负责。不改变磁盘格式或隔离承诺。最终性能门禁保留到用户要求的最后优化窗口。
