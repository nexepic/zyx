## 发现并修复的语义缺陷

新增原生 trail oracle 在包含平行关系和自环的 3 Node/4 Edge 图中预期 7 条路径，实际仅返回 4 条。通用变长遍历及批量计数优化都错误地禁止路径重复 **Node**，排除了合法的自环及重访节点路径。现改为每条路径记录已使用的 **Edge ID**。通用遍历使用计费 PMR 身份集合。平行 Edge 仍不同，同一条路径不得重复使用同一个 Edge。两个自环应产生两个一步及两个两步 trail，不产生三步 trail；命名路径输出与优化 COUNT 结果一致。方向、端点、完整源校验、深度/工作量/行数/字节上限及取消均保留。

真实 Kuzu0.11.3 非计时检查通过显式 `*TRAIL 1..2` 独立确认相同的 7 行有序结果。Kuzu 默认递归模式为 WALK，返回 8 行，包含再次使用自环的路径。该差异记录于 kuzu-trails.json，不将不等价语义宣称为等价。后续变长路径比较必须显式选择 TRAIL，才与原生关系唯一路径合同一致。现有固定跳数工作负载预检继续通过。持久格式及 ABI 不变。

## 预算回归定位

最短路径测试 `ShortestPathRetainsNodesWhileAdmittingEdgeBatch` 在精确的改动前 a487f7c7 源码上也因固定 9000 字节阈值失败：Node 保留已消耗预算，尚未进入 Edge 准入。没有削弱其必需的失败合同。测试改为在有限小范围寻找实际的“保留 Node 后准入 Edge”边界，要求共享字节超限时尚未复制任何 Edge 批次，并保留 16000 字节下完整结果的断言。Edge 载荷为 1200 字节，因此 128 字节搜索增量小于目标失败区间。校验实际阶段而非假设容器尺寸，使测试跨平台。改动前失败日志独立保存。
