# S1：完整批扫描契约与候选决策

计划 `scan-path-20261023`。本记录是待实施设计，不声称生产支持。S0 的 16 项语义核验和冻结基线为前提。只选择以下两条候选；候选测量结果不能改变冻结的选型规则。

## 1. 决策与排除项

保留 LogicalGraphReadSnapshot、现有类型化列消费者、单文件 COW 发布与逻辑 ID。增加的是存储提供的完整扫描批能力，不能把标签索引输出、实体校验、属性列读取继续当成三个互不关联的逐实体接口。

A：ROW 上查询局部的认证批视图。一次批构造同时解析实体/标签与选中字段，持有页面 pin/受预算拥有的回退图像，将同批所需的位置、可见性和字段选择证明交给消费者。ROW 的第一次访问必须真实验证。不可使用跨查询整库物化、预计算查询结果或放大缓存容量使热测量获胜。A 不改变持久格式；它是较低复杂度候选，也可能达不到 5 倍门槛。

B：具有实体可见性与标签成员证明的持久扫描块，类型化字段块与通用 ROW 回退共享同一个快照根。字段块只解决属性读取，因此必须同时具备可直接枚举 live IDs 和 labels 的权威信息。现有 13/39 字段组没有完整的批扫描标签证明，不能直接宣称已提供 B。B 需要新的实验格式及源规范，不能修改当前 13/39 的解释。

两候选复用同一消费者，不加新的过滤器或聚合器。不引入更新日志层：首版只实现局部块 COW；若更新守护过不了，候选拒绝，不自动扩展为 LSM 或多层合并。

## 2. 批契约

请求绑定快照、逻辑扫描范围、规范化标签 token 集和字段 token 集。批数据按稳定逻辑 ID 递增，不重复；通用 gather 的重复/顺序恢复仍留在既有 gather 路径，不能改变扫描顺序合同。

一个批包含：最多 512 个 EntityRef、逐实体可见性、已认证标签条件的选择位图、字段的类型/缺失/NULL 状态和数据视图。512 沿用当前执行器 DEFAULT_PROPERTY_BATCH_ROWS；允许因字节预算收缩，不能为 benchmark 单独扩大。字段集合来自计划依赖，禁止只取当前 WHERE 的字段而丢失投影或聚合所需字段。

认证身份包含 database ID、数据区域身份、物理根、generation、语义 fence、schema/token identity 及适用 I/O epoch；批句柄还包含 owner/incarnation。借用只在生产者回调内有效；返回值必须独立拥有。任何失败、重新填充或回退使旧批句柄失效。

缺失与显式 NULL 分别编码；空字符串/嵌入 NUL 保持字节语义。混合类型通过类型分区或逐值状态表示，不能转换整数为 double 而损失精度。NaN、负零、溢出、COUNT、DISTINCT、tuple 等语义沿用现有消费者。

同批认证只可复用已经验证的不可变源。检查 scope、slot generation、owner、完整 offset/token 目录后才可发布 ROW 选读。mutable overlay 仍按原 fence 检查；不授予旧证明跨事务写入后的有效性。已持久化成员证明只有其写入/恢复不变量实现并测试后才能替代 Entity Map 再读。

能力接口必须在首个输出前明确 supported/unsupported；开始输出后禁止转入另一条全扫描路径。预算不足在输出前回退，输出后的失败终止查询并由原事务/结果层处理，不能返回前缀成功结果。

## 3. 资源与复杂度

每批至多 512 实体，共享至多 1 MiB 临时源工作区，且仍受调用方剩余查询账户限制；实际可用量取两者较小值。1 MiB 是扫描阶段子上限，不是新增预算。raw buffer pool 保持 64 MiB，metadata cache 保持 128 项/1 MiB，不增设独立数据缓存。输出与聚合状态继续由原账户记账。

每个持久扫描块覆盖最多 512 个连续逻辑 ID；块不等于标签表。最多 64 个块内类型化字段、64 个块内标签，记录超限、复杂值或不合算的字段使用通用回退；不能截断字段/标签。块内候选数据总编码尺寸至多 1 MiB；大文本/集合不强制内联。字段选择以通用密度、类型稳定性和编码总成本决定，不识别字段/标签名称。

A 的首次成本仍有 O(实体数 × 实际验证的属性目录宽度)，但共享页定位、候选/实体交付、批身份与消费者准备。必须记录残留成本，不预测其必然达到 5 倍。

B 的元数据定位/验证目标为 O(访问块数 + 访问页数)，数据值检查仍为 O(输出/检查值数)。标签筛选使用块成员位图与存活位图交集，字段值不经每实体属性根定位。通用回退部分单独统计并计入端到端；不能只报告成功采用的块。

记录峰值真实账户、页读写、实体/属性根次数、块数、回退比例、首次读取及维护成本；不能把固定 sizeof 累计冒充内存流量或实际峰值。

## 4. B 的格式与构建决策

当前默认 5/31 和实验 13/39 字节均保持原义。B 实施前必须在存储规范补齐新的实验版本、所有 wire 字段/校验范围、未知标志拒绝、页 owner、manifest 寻址及版本兼容规则，并更新编译/读写拒绝测试。没有完整 wire 规范不得写入候选文件；本决策不预先占用未核对的版本号。

块描述信息至少包含 ID 区间、live bitmap、标签成员位图或其认证引用、选中字段 token/type/缺失/NULL 信息、类型数据/通用回退引用和源版本。描述符与字段图像纳入同一快照 fence、完整 integrity、旧 pin 及退休机制。压缩只在包括 metadata 的总成本划算时采用，RAW 是合法回退。

采用新实验格式时使用显式离线目标文件构建：原数据库只读，稳定逻辑 ID/图语义保留，候选写入独立目标；不覆盖源、不把半成品作为用户数据库。固定输入可以先用现有 loader 按同样语义创建 ROW，再由真实转换器处理；不能安装伪造 descriptor 或依赖 benchmark 专有字段。

离线构建有界地逐块读取/写入，未完成文件明确处于构建状态；只有完整目标的 integrity、全库空间和资源准入成功后才生成可打开的完成状态。任意失败删除本次私有目标或保留为不可打开的失败证据，不能发布前缀。构建状态、恢复/拒绝协议仍须在 wire 规范中完整描述。

稳态按整个候选数据库核算，沿用至少 10% 节省门槛；源、目标、临时文件同时计入转换峰值和原 2 GiB 注册文件合同的总构建文件预算，不把保留源的成本隐藏掉。维护单次工作区至多原 8 MiB；块编码工作区至多 1 MiB。若准入拒绝，整个输入记为拒绝而不是从结果中删除。

既有 8×64-owner 公共转换入口保持原边界，不循环发布小前缀冒充完整目标准入。B 采用新的完整目标构建协议才可服务 medium/holdout；这是候选必要转换，不是另建通用迁移产品。生产普通写入仍使用原单文件事务协议。

## 5. 更新、快照与维护

A 没有持久状态；按查询作用域释放所有视图。更新后新读取重新绑定当前 snapshot，旧 pin 继续读取原源。

B 在事务中 COW 受影响块，变更字段、live/label bitmap、主记录和目录一起发布。类型变化/密度下降/尺寸超限时，该字段或受影响块降级为 ROW；不能留下依赖陈旧字段块的 reader。新实体/删除/多标签增删都要更新同一权威信息。

首版最大读取合并层数为 1：一个当前已发布表示加既有事务 overlay，不建立持久 delta 链。重组是显式维护，最多一个 512-ID 块/次，不在查询内触发隐式整库整理。旧 pin 阻止回收；没有峰值额度时原子拒绝维护并保留原布局。

单块更新可能写放大；必须以 S0 的 SET、批边、删除和完整实体守护证明可接受。不能以查询收益抵消未披露的写入退化。GC、LargeValue、搬迁、崩溃恢复、取消及完整 integrity 在 S3/S4 全部覆盖后才允许生产验收。

## 6. S2 判定与实施顺序

先实现公共批契约与 A 的有界生产接入，并用受影响模块验证语义、认证、借用和失败边界；再实现 B 的最小真实持久构建/读链，至少包含修改后读取和重开。两个候选都完成必要语义检查后，才开启一次已登记比较窗口，避免每改一个函数就跑性能。

一次窗口包括四主场景/两数据集，并分别记录未采用或失败。候选测量至少三进程、三预热十正式样本，实际首次使用、构建/维护成本另外保留。不能用热缓存成绩代替首次使用成本。原 S0 非计时 oracle 为唯一结果口径。

每项均达 5 倍且资源/空间/必要语义通过才选用；若多者通过，优先更小维护与写入成本，再比较端到端性能。只有明确实现 bug 允许一次定向修正，不进行新的候选搜索。失败停在 S2，记录未解决成本；不预先记入 S2 的 20%。

当前仅 S1 设计交付；上述能力尚未实现，性能无新增收益。wire 规范属于 B 实施前的强制产物，不得凭本记录跳过。
