# R3.2 bounded field transition and snapshot contract

Parent `ba8cf295`; implementation checkpoint, not a preregistered performance run. R3.2 remains in progress and total accepted progress stays 13/24. No native hybrid file writer, format or graph route is installed.

`PropertySubblockFieldTransition.hpp` adds a pure bounded transition for one existing admitted column. It returns no change, one replacement column, or demotion of only that field into at most 64 cells. It accepts no extension/ROW source to auto-promote. Stored NULL stays present with zero payload; REMOVE clears presence. A type change or 48→47 occupancy transition demotes the selected field. The demotion result invalidates its unused Column member so an accidental encode cannot publish a fabricated scalar zero. An opaque extension marker refers to the caller's retained canonical input, not an encoded value or invented large reference. Other field/large bodies are never accessed by this kernel.

`validateColumnSnapshot` records the R3.1 liveness/generation decision: current group live is authoritative; historical column live may differ only on absent cells. Require presence within current live and column-generation <= group-generation <= descriptor-generation <= visible generation, matching group/owner/database and required namespace roots. Authentication of expected token/native page/slot still belongs to the native reader. Owner creation/deletion without this field therefore need not rewrite unrelated columns. A dead owner retaining a present value rejects. Native EntityPropertyKey ID limits remain unchanged.

No-op matches ROW's actual PropertyValue equality: int and double are distinct, signed zeros compare equal, NaN compares unequal even with identical payload bits. Replacement encoding still preserves IEEE bits. Review found that an initial bit-equality implementation would disagree; correct both the kernel and its expectations, then add a test comparing all 144 pairs of 12 primitive/missing/NULL cells against actual optional<PropertyValue> equality. `before-semantic-review-32.json` is preserved as an intermediate result, not evidence that the old equality contract was correct.

Entering the pure kernel requires a caller-provided bound sufficient for sizeof(FieldTransition), and a native usable-record bound; changes over the fixed staging/record bound fail without mutating the const input. This check does not reserve a real account. The native caller must acquire/hold the actual R6 reservation before entering and until the plan dies, admit canonical extension input and all map/allocator plans, and publish ownership/index/descriptor/fence changes atomically. Changed generations must advance. No-op causes no replacement. Complete reverse conversion, global integrity and field retirement are not implemented by this isolated kernel.
