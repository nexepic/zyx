# 最终控制记录缓存一致性与端点归属

发布认证正确拒绝了新分配但在缓存池头中仍标为空闲的帧。受控的“写入前读取”交错稳定复现缓存回填间隙。现在缓存池用同一把已有互斥锁覆盖失效清理与精确控制记录写入；部分写失败不会保留可覆盖幸存记录的脏缓存。认证检查保持强制。

完整 medium 准备另暴露出：变更暂存前的端点校验没有显式分配归属。事务快照的存在性探测现在默认使用事务 WRITE 额度，并保留显式调用者的额度。CACHE 满的反证在修复前失败、修复后通过；不提高资源上限。

局部 117 项缓存／I/O 测试和 58 项后端资源测试通过；最终 102 个指定模块、142 个套件的 2,182 项测试通过。未执行全量单测。有界多线程重放、新源码冻结和新鲜完整输入准备另行追踪；本文不宣称性能验收。
