# A2 普通 SET 与 map 合并字段增长准入

日期：2026-10-12。普通非 NULL SET 统一通过 assignBoundedProperty，在新增字段前检查 maximum_property_entries，更新已有字段仍允许。连续读侧修改、CREATE/FOREACH、MERGE ON CREATE/ON MATCH、MERGE 后续 SET 均接入该检查。

四处 map merge 逻辑统一为 mergePropertyMap：先验证 map 类型及 key，统计 NULL 删除后的剩余字段，再准入真正新增字段；所有检查通过后先删除再写入。避免哈希遍历顺序导致最终合法的删除加新增被拒绝，也避免一次 merge 的暂存字段数超过限额。保留每遍遍历的取消检查、无变化比较与各调用方 property cache 同步。失败只影响未发布暂存数据，整条链仍沿既有原子发布边界。
