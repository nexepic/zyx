# A3 候选封装成本纳入选择

日期：2026-10-12。

列布局候选计数加入 48 字节完整容器头、槽位和成员目录两个 8 字节区段头，以及每页 8 字节区段头。常量由候选接口定义，codec 复用头大小；decode 的列布局 bytes 与 builder 计算一致。额外候选元数据参数仍需计入容器之外的实际生产引用成本。

共享字段候选由 2224 更新为实际封装 2296 字节，测试直接对比 encode 输出长度；独有字段保留现有原根 3456 字节，实验原根容器为 4016 字节，其封装仅用于实验传输，不将它当作现有生产根成本。两种布局 decode.bytes 与构建成本往返一致。

五个限定模块共 98 项通过，同名 results 目录保存日志、JSON 与源码 hash。该计数仍不含生产页目录、manifest、页填充与旧快照，不能宣称完整文件空间或性能准入。统一预算、生产路由发布及回收待完成。

进度保持 S0 25%、S1 14.3%、S2–S6 0%、总体 2/34（5.9%）。未运行全量测试或 benchmark，未提交或推送，未修改正式数据库文档。
