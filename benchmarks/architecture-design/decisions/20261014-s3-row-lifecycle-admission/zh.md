# S3.2 原生属性生命周期原型与准入

A3 的容器列实验仍被拒绝：它读取/替换整个容器，缺少权威图路由及持久 owner 退役。不启用 MIXED/列组根。获准替代方案保留现有 owner-keyed ROW 权威、实际键枚举、选择性读取、COW 发布、索引及快照安全 LargeValue 退役。

原生 opt-in ROW 原型通过有界逻辑 chunk 切点，把大字段体与相邻小字段分开。规范属性字节及其按 token 排序的偏移目录保持相同。大字段 token 和六字节值头保留在前面的紧凑分组中，使存在性/non-null 探测无需加载大字段体。相邻小字段共享 chunk。已有 Manifest 偏移/长度描述变长 chunk，不增加持久根、codec、命名空间、版本或冗余完整行。LargeValue 层仍与属性领域无关，发布前校验最多 4096 个有序、非零切点。流式数据及多级 Manifest 物化按实际区间计算，不再假定“序号乘固定 extent”。

`PropertyRowChunkPolicy` 考虑 RAW 根、最多 2048 字段、至少一个已有 16 KiB extent 的大字段，以及没有调用者自定义切点的情况。仅当首次使用 chunk 更小且估计编码分配增加不超过 5% 时准入。估计包含数据/Manifest 帧及当前目录/catalog entry 宽度；共享池取整、分配器/COW 路径和旧版本保留独立计量，不宣称这些免费或普遍受该估计上限限制。压缩根、小根、过宽根或成本不合格时继续普通 ROW，不丢字段。元数据受数量上限约束。保留已有写侧准入/RSS 边界，进程级资源协调仍属 S5。

## 实际原生生命周期

opt-in 后端通过 NativeGraphWritePlanner 和 PropertyCollectionRootStore 写入真实图 Node。测试覆盖大字段字节不变时的小字段类型变化、存储 NULL 与 missing、字段移除、大值转内联、整实体删除、有界持久可达性回收、旧 pin 保留旧完整值、释放后的退役，以及关闭 opt-in 后重开。新引用使用同一可信 owner 路由。通用原生测试另覆盖变长 chunk 数据帧搬迁，保留旧/新快照和不可变引用 generation，跨切点范围读取，以及有界流式写者的多级 Manifest 物化。checksum、owner/generation 校验、数据先于根原子发布及退役要求继续保留。

在两个真实原生 store 中分别创建一个含 256 KiB 字符串和标量的实体，使用相同的 64 KiB raw-page pool。各读路径在重开后开始，不计 open-time IO。成功 positioned IO 及完整文件大小包含路由、描述符、分配器/目录和数据工作。这是字节/空间观察，不是延迟、设备 IO 或 RSS 结果。

| ROW 放置 | 标量点读字节 | non-null 探测字节 | 完整 Node 读取字节 | 完整文件字节 |
| --- | ---: | ---: | ---: | ---: |
| 现有均匀 chunk | 245760 | 237568 | 827392 | 2228224 |
| 成本准入切点 | 180224 | 172032 | 843776 | 2228224 |

完整读取工作略增；此案例选择性访问少读 65536 字节，共享池取整使文件大小相同。不据此证明普遍加速或稳态。singleton/小根维持现有 ROW，可能放大页成本的 16 KiB 候选明确不准入。

最终通过 **6 个相关 suite 的 129 个测试**，包括 8 个新增切点/原生生命周期用例，以及已有 LargeValue 压缩/范围/内容身份/维护/损坏、属性 store 的归属/缓存/校验、原生完整性检查。低维护预算不足以原子退役一个完整值时，在发布前失败；生命周期用例为其 75 页值配置有限的 256 次退役上限。未运行全套或性能基准。

验收 S3.2 生命周期原型及准入决策：保留 ROW、准许有条件逻辑切点，拒绝未接入权威路由的整容器列载体。原生默认启用及规范更新属 S3.3，专门的最终故障矩阵属 S3.4，O3/O5 延迟/资源门禁属 S3.5。本检查点后端 opt-in 默认仍关闭。
