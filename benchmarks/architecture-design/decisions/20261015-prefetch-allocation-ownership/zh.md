# 协调 Property 预取分配归属

本检查点不新增验收项，仍为 22/34（64.7%）。

协调 Property 预取现将 BoundedBatch 的共享 PMR 容量与载荷保留统一管理。缓存充实先向同一保留申请额度、再重算估计值；拆分/重新成批移交嵌入行归属，不先退款再申请载荷。命中行向下游移动时保留独立计费；被过滤行原地销毁后才退款，避免丢弃窗口少计，也不为丢弃行额外申请独立对象。

原生非抛错所有权移动下，appendCharged 将输入值放在计费保留之后销毁；插入被拒绝时先销毁输入载荷、再回滚批次计费。新增测试在实际载荷析构期间观察预算，而非仅在退栈后检查零值。泛型抛错移动类型保留原有后备行为，原生行/记录移动为非抛错。未协调接口保留原有逻辑字节契约。

真实原生 Property 过滤在 32 KiB 账户下连续执行命中、全过滤、再次命中；结果保留计费与账户一致，释放结果后查询计费归零。最终源码通过 28 个套件的全部 681 个定向测试。未运行全量单测、性能测试或提交推送，因为尚无新的固定验收项完全闭环。证据归档及源码散列见 proof.json。计划/写入/维护、临时工作区审计、积压准入及分区 hash/aggregate 仍待完成，S5.3/S5.4 尚不能计为完成。
