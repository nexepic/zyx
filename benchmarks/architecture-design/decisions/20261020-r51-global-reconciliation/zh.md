# R5.1 覆盖树候选：全局核对与物理生命周期

本检查点继续原固定五项中的 R5.1，没有新增验收，总计仍 **13/24（54.2%）**；未提交/推送，未重跑性能窗口。

## 实现

CoveredAdjacencyCandidate::verifyIntegrity 在同一来源 pin 下执行两遍核对：

1. 遍历候选固定 map，继续拒绝重复逻辑前缀，并认证每条记录与当前主 Edge 的方向、owner、邻居和 type 完全相同；孤儿及合法 checksum 的错误 suffix 拒绝。
2. 通过新增有独立元数据页上限的原生 Edge Entity Map 逻辑游标，认证全部主 Edge/端点 Node，逐条核对精确的出/入方向记录，并核对总计恰为两倍边数。缺失反向项不能由正确的出方向点读掩盖。

候选条目及主 Edge 数上限在工作前检查，乘法/lookahead 防溢出；主 Edge 元数据树的页数独立计数和限制，不将记录上限冒充页数上限。报告只在两遍均完整且最后 checkpoint 通过后返回，带数据库和快照 generation，仅为该 pin 的检查结果，不授予缓存/写入或生产准入权限。取消或不完整扫描不输出成功报告；重试独立完成。该全局检查没有接入查询规划或点读回退。

物理生命周期复用已有类型化 B+Tree compaction：实际搬迁覆盖树全部来源页，原逻辑根 PageId 不变、目的池物理 generation 重新绑定。旧 pin 继续通过完整检查，并阻止来源池释放；旧 pin 释放后才能回收。将来源物理槽复用给不同 Segment/Index/generation 后，候选树仍通过全局检查及重开。旧 continuation 不可用于新 generation。没有恢复已退役的 per-node root/delta 布局，也没有删除主记录认证。
