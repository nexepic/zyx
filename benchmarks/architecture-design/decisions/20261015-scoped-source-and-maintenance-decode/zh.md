# 私有源读取及维护解码额度

这是组件证据，尚不代表 S5.3、S5.4、S5.5、S6.1 或 S6.3 验收；累计仍为 22/34（64.7%）。

同步借用的解码作用域在解码前检查完整编码形状、申请标准容器载荷的审计上界，并在实际递归构造中执行取消检查。调用方将额度保留到源值销毁。嵌套作用域替换申请方并继承未覆盖的取消检查。overlay 首次读取源实体、提交提取属性差量、完整性扫描和大值所有权扫描按单个源集合安装作用域。

数组槽位、属性目录和大值读取的标准输出缓冲在分配前申请额度。整个目录的顺序、偏移和 token 校验先于额度拒绝，避免用资源错误掩盖后段损坏。没有外部预算回调时，不再传入空操作包装来绕过内部计费。

大值读取使用拥有分配资源的临时分块；RAW 转移已有缓冲，压缩分块的输入、输出分别计入真实重叠。每页临时解码额度及时归还。范围缓存保留资源直到缓存释放，能够跨解码作用域继续计费。显式回调路径继续由该回调负责，分块使用永久普通分配源，避免把同一分配再次记入 PMR。

有限预付额度支持事务性的外部预约增长：拒绝不改变已有预约；释放缓冲后可缩减，移动后的空预约不能重用。维护扫描按集合释放载荷额度，而非累积到全库扫描结束。测试验证拒绝和重试、完整字段一致性、关闭后额度归零及扫描不发布写入。

本目录冻结源代码、审计清单、模块结果和独立进程故障证据。较长故障路径抽样，不能表述成穷举。堆大小指分配请求上界，不是 RSS；没有运行新的性能基准，也不声称超越 Kuzu。未覆盖的读取名称/目录工作区、编译器/IR、其他发布及维护路径仍须后续闭环；MSVC 默认容器代理的物理 OOM 行为和另外两平台运行结果不在本次 Linux 证据内。
