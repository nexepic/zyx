# 最短路径临时状态的分配准入

旧实现的 BFS 队列、深度/父节点哈希表和返回路径只受局部逻辑大小约束，没有对实际内部容器请求执行共享准入。反证用例在 1 字节调用方额度下读了 3 次邻接才失败。

队列及两张表现在使用保留强所有者的分配器，计入 deque block、桶数组和节点的实际请求；返回路径使用拥有额度的数组并保留到过程结果物化结束。局部工作量上限保留，避免将逻辑估算重复计入共享账户。两个端点改用栈数组和去重视图。

两个新用例验证首次读取前拒绝，以及读取后容器分配被拒绝时部分状态完整释放、再次执行正确。后者按读取检查点拒绝请求，避免假设 libc++/libstdc++/MSVC 的 deque 块尺寸相同。6 项过程身份/资源测试和 10 项 Cypher 算法语义测试全部通过；未改断言掩盖旧行为。

本改动不更新整项百分比，不代表其他 GDS/编译/运行工作区全部完成。没有全量测试或新性能评测。反证、最终日志、XML 及源码 hash 随本记录保留；仅有 Linux Clang19/libstdc++14 运行证据。
