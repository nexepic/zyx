# A3 稀疏 canonical 回退载荷

日期：2026-10-12。

AdaptivePropertyColumn 的 canonical 回退改为 presence 掩码加连续的实际属性根。缺失槽位不再编码空根，也不占载荷容器条目；NULL 仍为存在的属性。读取按低位 popcount 定位根，并校验槽位身份及恰好一个固定 token。第 63 槽位不使用移位 64，跨平台使用 C++20 bit 操作。

编码字节计数增加 8 字节 presence 掩码，根载荷只随实际存在属性增长。新增 64 槽位、仅两个存在值的测试，验证完整读取、末槽位、NULL、精确字节上限、少一字节拒绝、插入首槽位后的 rank 和旧对象不变。五个限定模块共 71 项测试通过；同名 results 目录保留构建日志、测试日志、JSON 和源码 hash。

该计数仍不是完整持久化 descriptor 或内存预算：布局 tag、行数、偏移目录、allocator 和编码瞬时缓冲区尚未计入。载体仍是实验内存对象，不代表生产空间或性能收益。后续需统一描述符、共享页定位、权威实体路由、预算、取消和原子迁移回收。全列替换仍存在。
