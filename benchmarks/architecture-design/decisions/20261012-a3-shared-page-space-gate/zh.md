# A3 共享页的稀疏空间反证

日期：2026-10-12。

新增结构成本测试，64 个 owner 各有一个 int64 值。现有实体属性根合计 3456 字节；共享字段的共享页为 628 字节；64 个独有字段的实验镜像装入两个 4096 字节上限页面，实际编码字节合计 6448，为现有根的约 1.87 倍。

共享页已经减少逐列 LargeValue 引用的需要，但完整 Adaptive 镜像的 32 字节外头、48 字节固定列头与 12 字节页目录仍重复。独有字段情况下，即便尚未加 owner 表、成员目录、生产页目录及 manifest，已超过现有属性根。因此拒绝将当前完整子镜像共享页直接用于所有属性形状的生产布局。后续需压缩子列头、共享身份/校验，或对稀疏形状保留原布局，不能仅凭共享字段结果采用。

这里只比较 codec 字节，未运行计时、完整文件空间或 RSS benchmark。五个限定模块共 84 项测试通过，同名 results 目录保留日志、JSON、源码 hash。已有原型保持可用于语义、取消和拆页验证，生产格式不变。
