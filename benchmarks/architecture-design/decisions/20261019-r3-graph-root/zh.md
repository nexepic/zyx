# R3.2 普通图发布骨架

本次为基于 `6a3fedf1` 的未提交工作区，验收仍为 13/24（54.2%）。百分比未增长，不提交／推送；固定五项均未完成。源码清单和补丁标识累计候选，包含此前的私有字段页工作。

元数据图发布器接收有界类型化根变更，不暴露带元数据权限的图回调。在 writer fence 内检查数据库／旧根，并在准备数据前认证已存在的描述符；模式、部分根、重复命名空间、矛盾 clear 在图页准备前拒绝。最终 Index 根分配后，再从本次最终根或当前保留目录解析引用，拒绝缺失／退役根并使用真实 batch generation。空描述符替换／清除与普通图数据共用一次发布，不制造 bulk scratch 或此前一次 ID-only 提交；既有默认调用方不传该请求。

实验准入不变：格式 32 仍只允许空描述符，非空根拒绝。测试覆盖普通 Index 数据已准备后的拒绝，并验证重开／重试时旧图仍完整有效。新树与保留树可以解析，但不代表已获准的 hybrid 字段路由；marker 是通用测试 Index，不是已发布属性子块。字段页图像仍属私有，尚未安装原生字段池／owner kind、转换或属性读写路由。

新测试覆盖 data＋descriptor 恰好一次 generation／LSN、旧 pin／重开、清除、陈旧／错误数据库及根、checksum 合法但旧描述符身份错误时在数据准备前拒绝、缺失／保留／退役根、已准备数据／退役的回滚，以及每个 A/B 中断恢复完整数据／描述符配对。既有持久化顺序与语义 fence 保持；这不代替完整字段生命周期、磁盘／资源故障矩阵或同执行器 ROW／成本对照。

四个必要模块：新 graph-root 发布、既有原生描述符 store、NativeGraphWritePlanner public contracts 和元数据 validation boundaries。默认 Debug＋coverage：48/48 通过；隔离构建：66 项中 65 通过、1 项默认格式专用测试按预期跳过。数量不同是因为原生描述符／发布用例只在隔离格式中编译。仅 Linux x86_64，未跑全量单测、正式性能、Kuzu 或其他平台。保留范围／结果、二进制 hash 及未提交源码身份／补丁；本次发布骨架修改的测试均通过。

加载既有工具链后，用 `python3 run-necessary-modules.py BUILD_DIRECTORY OUTPUT_DIRECTORY` 复现；在记录的 base 上应用 `source.patch` 可还原准确候选。`verify-evidence.py` 校验当前源码 hash、原始用例／跳过数和文档派生进度。此前 image 检查点可由其独立补丁还原，不能把旧检查点的当前树校验当作后续修改仍匹配旧工作区的声明。

后续须接通元数据持有的早期字段 ID／typed pool 准备及 locator key，完成全部字段读写／索引／overlay／大值归属、双向转换及退役／完整性／故障，补全实际原生分配成本估计与同 R1 执行器 ROW 对照。所有必要部分接通前保留非空根保护；R3.3／R5 准入合同不变。
