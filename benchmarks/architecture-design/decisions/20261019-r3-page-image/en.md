# R3.2 private shared field-page preparation

This is an uncommitted working-tree checkpoint based on `6a3fedf1`. Progress remains 13/24 (54.2%); no commit/push is performed because accepted progress has not increased. None of the fixed R3.2/R3.3/R5.1/R5.2/R5.3 deliverables is complete. Source hashes plus the working-tree patch identify this candidate without inventing a commit identity.

`HybridPropertyPageImage` packs group/column/extension payloads into the existing neutral SlottedPage representation. Multiple groups share one image; no per-owner/per-column dedicated page is required. Typed updates validate expected field identities and preserve unaffected slots. Private clone, byte reopen, erase/reuse and compaction exercise stable logical page/slot/generation references. These are private images, not published pools, real graph snapshots or a native format/root switch. The class assigns no logical IDs, segment/page owner kinds or descriptor roots and must never be persisted as an ordinary ROW page. Existing nonempty descriptor guards remain.

The extension directory is now explicitly fixed-width: ordered 12-byte owner/token prefix plus 16-byte locator, with the 48-byte envelope and variable body in a shared field page. `HybridPropertyDirectoryCodec` also provides native owner/column/group keys and selectors. Reserved bits, invalid native IDs, no-slot sentinel and zero generations reject. A valid page CRC and locator do not authorize a wrong record role. Fixed maps reuse the existing canonical mutation mechanism. Payload-bearing variable keys were not adopted because native internal separators retain complete keys; that mechanism can lower fanout and duplicate large fields. Locator/page reads add costs that the full R3.2/R7 controls must still measure and admit.

Data pool physical generation is independent of semantic commit visibility: columns at generation 7 may live in a pool of physical generation 1 when group/descriptor/snapshot bounds hold. The descriptor metadata frame has separate physical publication rules. `decodePayload` serves private source identity checks; graph-facing column decode retains full group/descriptor validation and avoids another payload-validation pass.

`SlottedPage::readOwned` and `serializeOwned` require a destination allocation owner, admit the actual copy through that resource and retain it through escaping buffers. Existing APIs and wire bytes stay unchanged. Tests cover quota refusal/refund/retry, source immutability and resource lifetime. Fixed codec/compaction scratch remains an explicit obligation of the future bounded publication coordinator; these buffer tests are not whole-query/RSS or full resource admission evidence.

Four necessary modules pass 48/48 cases in each default format-31 and isolated format-32 build: the new page-image/directory cases, native field records, native extension envelopes, and existing SlottedPage module. These are the same 48 cases across configurations. Linux x86_64 Debug with coverage only. No full suite, formal timing, Kuzu comparison, other-platform execution or production admission. Raw results/scope, source identities/patch and binary hashes are retained. Reproduce after sourcing the existing toolchain with `python3 run-necessary-modules.py BUILD_DIRECTORY OUTPUT_DIRECTORY`; `verify-evidence.py` checks current source hashes, raw scope/counts and derived progress.
