# A3 自适应属性归属与页成本合同

日期：2026-10-14。S1.3 设计交付。保留当前生产行布局，拒绝现有实验载体直接替换生产。S3 接入、生命周期及性能仍待验收。

## 有界分组与唯一权威

Node/Edge ID 空间分开。目标容量为 64 个逻辑 ID：非零 ID 对应组 `1 + (id - 1) / 64`，槽 `(id - 1) % 64`。标签只保留成员关系，不复制属性组、不触发实体搬迁。逻辑 ID 不复用，物理槽保持 generation 校验。存活位图区分删除和不存在，稀疏组不为密度而压缩逻辑 ID。

组采用 ROW 或 MIXED 模式。ROW 保持规范的 owner-keyed 属性集合。MIXED 中，列 presence 标记的活跃槽由列权威持有，其余字段由有界行扩展持有；owner 枚举列出该实体实际键。列和扩展归属必须不交且完整；缺失、存储 NULL、有效值保持三态。扩展不保存第二份完整行。点读核对选中归属，完整读取枚举实际实体键，不遍历全组/全库 token。不一致报损坏，不回退为缺失值。

首版限定整数/浮点/布尔列，带 presence/null/type 信息，采用紧凑稠密或排序稀疏/rank 存储。非定长、混合类型异常和大值走有界扩展及认证 LargeValue 引用。类型变化不建立永久 schema。读取标量不能解码无关大值；大值体独立不可变路由，小更新复用未变引用，不能重新复制无关字节。

低密度组共享单组路由目录和紧凑页，不预设每字段/实体树、每 owner 独立根或每组独占尾页。路由描述符认证数据库、实体种类、组 ID、出生 generation、布局模式、存活位图、枚举/扩展路由及列子块位置。位置使用逻辑页 ID 和有界子块身份，经当前页映射解析；标量列不逐个保存完整 LargeValueRef。精确定位符/codec 位宽先经 A7 审查，本次不修改持久格式。

## 访问及 COW 路径

| 操作 | 当前行路径 | 目标自适应路径 | 修改的页 |
|---|---|---|---|
| 单实体/单字段 | token、属性 owner 目录、属性根，可能整集合 LargeValue | token、算术组/共享目录、描述符、owner 键成员、选中列或扩展、认证页映射 | 无 |
| 完整实体 | 实体目录/页、标签、属性 owner 目录/根、全部实际值 | 同实体/标签；组描述符、实际 owner 键枚举及对应列子块/扩展值 | 无，不扫描 K 个无关字段 |
| N 实体/f 字段 | 排序 owner 位置及属性根，大集合可读取无关载荷 | 组范围目录、有界描述符/presence、每组 f 列及实际异常 | 无 |
| set/remove/类型变化 | 旧属性源、新集合、属性页/目录，按需大值/内容/索引元数据 | 最新描述符、成员及选中共享页/扩展，保留无关列和大值引用 | 受影响数据、枚举/描述符、共享目录路径、语义 fence 根、索引与退役元数据 |
| 删除/回收 | 实体/属性/成员/索引、退役队列、分配器/catalog/页映射 | 存活位图、owner 枚举、实际列 presence/扩展，空组才改路由，索引与可达性退役 | 有界实际页/路径，物理回收等待旧 pin 释放 |

全部路径在同一元数据快照下解析且核对 owner/generation。即使稳定逻辑页只改变映射，属性写也必须推进 state-directory 语义 epoch 或已有属性 fence 根：当前七根图 fence 不含页/索引根目录。规范归属、组路由、派生索引及退役记录原子发布，旧 pin 保留旧布局。实验调用者持有候选 root 不代表接入权威图目录；LVID 差集只是退役候选，不证明无其他活跃引用。

## 包含元数据的成本关系

E 为活跃实体，F 为实际属性总数，K 为组内不同 token，G 为已分配组，f 为选中字段，P=4096 字节，h 为目录高度。B=64 限定单组实体工作，不代表无限字段/值也有界。定位/路由空间 O(G+实际共享页数)，owner 枚举 O(F)，不能 O(EK)。列目录 O(各组 K 之和)，受准入限制。B=64 时每列 presence/null 位图至少 16 字节，另计类型/版本/头；稠密载荷至多 64 倍标量位宽。稀疏头/rank 单独计费，扩展计实际异常值、枚举及路由。

每 owner token 在偏移/头之前至少四字节。当前原型 64-entry owner 表 1056 字节，64 个成员的紧凑目录 592 字节，共享定长字段 packed 页 576 字节：本地合计 2224，现行 owner 根 3456。singleton 候选在容器/原生元数据之前已达 4744，退化。每列完整 LargeValueRef 的稀疏载体共享/独有字段编码为 4142/16616，予以拒绝。自适应容器对 singleton 回退行模式，最终容器编码实测为 2296/4016，仍不是总分配空间。

分配元数据包括页目录（64 字节头的 4 KiB 叶中每 entry 32 字节）、catalog（每 entry 48 字节）、allocator radix/summary、共享池位图/头、元数据路由、退役队列及 A/B 超级块。索引根、token registry、内容索引和查询索引另计。物理池预留 128 KiB segment，31 个数据帧；部分填充和旧版本保留可能主导小样本。COW 成本为实际整页及目录/分配器/索引路径和发布 fence，不能等于修改标量字节。点读 O(h+owner 成员查找+选中页)，完整读 O(h+实际字段+对应页)，扫描 O(目录范围+Gf+选中异常)，更新另含索引和 O(h) 共享路径，删除另含实际字段/度数及延迟回收。

## 准入、有界工作与生命周期

转换显式且限制前台工作，不做后台自动调优。只有完全分配成本（路由、描述符、枚举、位图/类型、数据、索引、分配器、旧 generation 保留）优于行布局，且点/完整/更新预算满足时才准入。采用通用字节/填充成本，不能使用 benchmark 名、标签或特殊规模。随机交错形状、singleton 键、持续类型变化、删除后稀疏组可以保持 ROW。重编码/分裂至多访问 64 个 owner 和配置字段/字节上限，大值只引用。目标上限为每组 4096 个实际键和 1 MiB 规划字节，进一步受 A6 账户限制。超限保持 ROW 或按现有操作准入失败，不能丢字段。重打包只移动有界子块并原子更新认证描述符，不改变公开 ID。

转换暂存新归属及派生索引，验证完整枚举，发布一个 generation，共享可达性检查后才记录退役。逆转换同协议。空列/子块/组和旧描述符按精确 owner/generation 退役，全部相关旧 pin 释放后才复用。发布前故障保留完整旧图，不确定确认须重开。S3.2/S3.3 前必须有接入原生图的迁移、合法 checksum 归属不一致、大引用寿命、搬迁和回收测试。

## 实际页/字节证据与限制

新增原生测试执行 15 条生产路径：64 个共享标量实体；64 个共同标量加各自独有字段实体；64 个含 18 字段及 16 KiB 字符串实体。每路径前重开，raw-page pool 为 64 KiB，排除 open-time catalog/schema 加载。计量成功 positioned IO，按认证 owner 及 metadata magic/directory 分类，统计唯一物理 4 KiB 页范围。这是 IO/正确性观察，不是延迟、设备 IO 或 RSS 测量。读取次数含重复元数据工作，唯一页数不含重复。目录子类与父类总数重叠，不能重复相加。`delete_retire` 不强制后台物理回收。
