# GDS 投影、目录及过程结果的资源所有权检查点

投影节点/邻接数组、邻接哈希表、延迟 CSR 数组及其控制块现在保留分配所有者。CSR 离开创建作用域后仍使用原来的所有者，失败不发布缓存并可重试。构建期间借用仍有效的拓扑页条目，移除了两次关系类型字符串复制。公开的节点/邻接 const std::vector 引用接口保持原样；旧接口不借用临时默认 PMR。

投影规范、描述符及目录键的字符串/数组拥有容量额度。目录的两张表按需创建，桶/节点/控制块在创建前准入，清空不分配并释放整体状态。延迟提交使用准备时的所有者；目录准备中途失败恢复 revision 引用计数，包括构造参数已移交并释放写锁的情形。准备对象及回调闭包也拥有额度。listOwned 保留原生数组的归属，旧 list 输出继续作为调用方拥有的兼容边界。

原生自提交及事务过程从原始后端获取 CACHE 所有者，缓存构建/CSR 不占用创建查询的账户。过程安装 QUERY 作用域，结果构造时绑定保留额度，关闭后仍有效并在销毁时退款。OwnedStdString 增加受管 append/+=，支持自引用和已准入剩余容量；拒绝时保留原值。

本项不是全部 GDS/过程内存治理或 S5.3 验收。算法临时数组、其他过程缓冲及编译/CSV/绑定边界仍待完成，尤其不能由结果最终计费推断所有临时数据已在分配前计费。

## 验证与未通过项

显式选择 239 个相关测试，230 通过。新增 16 个测试全部通过，覆盖投影/CSR 所有权、目录/回调失败回滚、字符串拼接和真实后端 CACHE/QUERY 生命周期；目录准备逐点注入了 32 次申请拒绝，均无发布并完整退款。

其余 9 个向量低预算/批次测试未通过。控制实验取 882e7971 的旧过程源文件，使用当前头文件和其他依赖编译该单个翻译单元，在链接当前 core 之前提供旧定义；其 75 项向量用例有相同的 9 个失败 ID。该实验隔离过程实现，不冒充完整旧源码重建。失败原始 XML、日志、旧单元编译命令和具体 ID 均保留；未放宽预算、修改预期或跳过失败来宣称全绿。S6.1 仍必须解决它们。

本目录 run_selected_modules.py 在既有 Linux Clang19 coverage Ninja 环境中构建 core 和列出的单个测试对象，单独链接；会如实以非零退出码报告现有失败。只允许运行一个 Ninja 构建且至多 4 个编译进程，构建期间冻结 C++/头文件。无全量单元测试或新性能评测。仅有 Linux x86_64/Clang19/libstdc++14 运行证据。
