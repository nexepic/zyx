# A3 token 实际容量准入

日期：2026-10-12。

inline 与 LargeValue 输出 token vector 在 reserve 前报告请求容量，reserve 后报告实际 capacity，并检查取消。接口注释明确两次回调为绝对值，调用者替换旧 charge，不累加。A3 原型字段数量上限只检查首个请求值，实际容量由资源准入处理，避免 allocator 额外容量被误认为字段数量。

新增第二次容量回报拒绝及第二次回报设置取消的测试，验证立即抛出、后续正常读取。调整原有测试按绝对回报记账，目录阶段取消用例预期准入次数随新增容量回报更新，阶段断言保持不变。五个限定模块共 58 项通过，证据在同名 results 目录。

这是输出 token 容量边界，尚不等于统一预算或 A3 成员目录内存全部计量。原型累计目录和旧 vector 扩容峰值、inline 复制式读取缓冲、真实页生命周期仍待完成。进度保持 S0 25%、S1 14.3%、S2–S6 0%、总体 2/34（5.9%）。未运行全量测试或 benchmark，未提交或推送，未修改正式数据库文档。
