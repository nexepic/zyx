# 候选 A：跨批次复用已校验的 ROW 页面

这是 S2 实现检查点，不代表候选验收。总验收进度保持 15%；本检查点不包含性能对比、提交或推送。

选择性属性游标现在跨相邻批次保留至多一个已校验的槽页视图及其由缓存池计费的页面。此前会把最后一个借用页面复制为 SlottedPage，再解析一次，并在后续读取中逐槽复制。下一批次命中同页时现在复用原视图，换页则释放；切换读取模式会释放可选页面。缓存池关闭或容量不足时仍走原有复制路径。属性值和选择 token 仍需解码，owner、槽位和类型检查仍保留，因此这里没有消除逐实体 ROW 根的全部成本。

游标绑定原元数据存储和活跃代际。StorageIO 写入纪元（包含缓存池更换）变化时，保留的数据和目录镜像失效。消费过程中若有发布，剩余 owner 重新获取同一固定快照的页面，不重放已交付的 owner。文本批次在底层页面释放前消费完毕；消费者或预算回调抛出时，本次局部保留立即销毁，重试不会复用部分消费状态。

StorageIO 返回的 BufferPool pin 现在持有缓存池生命周期，移动构造和赋值也保留这一关系，确保两次调用之间关闭或更换缓存池不会留下悬空视图。直接使用栈上 BufferPool 的调用者仍负责原有生命周期。新增所有权不产生额外页面复制或独立分配。

定向验证结束后，结果与源码、库的精确身份写入 receipt.json。真实消费者测试覆盖别名、另一句柄发布后的旧快照、文本/标量批次生命周期、复制回退、复杂值/LargeValue/NULL/缺失、预算拒绝与消费者停止。不运行全量单元测试或性能矩阵。

首轮隔离格式运行通过 82/83 例。新增测试错误地要求完整读取保留了拥有型页面后，选择性读取仍必须持有 pin；实际路径正确复用了该拥有型页面。修正后的测试明确断言这种复用的 pin 数为零，再用新游标独立检查 pin 的移动与释放。没有削弱生产断言或回退逻辑；原始失败 JSON 和日志已保留。

首轮默认格式运行通过 159/160 例。新增的精确计数断言把此前 rank 读取与别名读取一起计入，得到 512 个 owner，而单次别名读取应为 256。测试现在紧邻别名读取前重置追踪，并断言该独立操作的精确计数。结果及回退断言保持不变；首轮记录已保留。

最终定向验证全部通过：默认格式 160 例（包含真实查询消费者）、隔离格式 83 例、隔离源/格式 24 例。两种当前核心配置均已重建。这些是存在重叠的配置用例数；没有运行完整单元测试集、性能对比或空间准入。S2 仍未验收，总进度为 15%。
