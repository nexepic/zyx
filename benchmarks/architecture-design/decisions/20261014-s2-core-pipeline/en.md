# S2.2 native scan/filter/project/aggregate integration

The implemented non-JIT baseline now connects selected native property reads, authenticated batch publication, typed predicates, scalar projection and numeric aggregation to owning public output. `BoundNodeScanBatch` preserves the existing bounded source matrix, binds an owning column layout, converts homogeneous integer/double fields where admitted and attaches a snapshot-bound Node EntityRef column. Every publication validates the complete matrix before consumer effects. Synthetic entity-column names cannot collide with real property keys. Source columns retain their existing pre-read admission and decoded-capacity accounting.

Bound Node predicates consume sealed column and batch row descriptors. Fixed primitive cells use stack-only scalar comparison values; mixed/string/list/map values borrow the already charged source and use the exact existing variant comparison semantics. Missing and stored NULL remain equivalent at the named property-read bridge; `exact_presence=false` prevents consumers treating it as an exact presence producer. Boolean filtering retains the existing typed primitive kernel when the numeric envelope bridge declines it; no permanent property-type schema is inferred. Selection intersects predicates and retains the original ordinal map. Batch selection publication preserves repeated ordinals and input order.

Before clearing rejected values or moving source cells into owning rows, the scan destroys all borrowed batch metadata. The row/column handoff remains an explicit charged adapter. Projection and generic aggregates use S2.1's operator-scoped bound expression inputs; the direct native numeric aggregate publishes its own envelope against the same query program/snapshot. This deliberately permits distinct batch owners at publication boundaries rather than extending a borrow across mutation. Output rows and QueryResult remain independent owners. Mixed values, unsupported reader capabilities and optional metadata pressure retain the existing charged semantic path. No source replay or accumulator replay is allowed after downstream effects.

Validation passed 33 selected binding/layout/scan-predicate/native integration tests and 222 selected execution/selection/filter/aggregate regressions. The former includes all scan preparation cancellation checkpoints, ownership refunds, changed schema, invalid Node-ID order, mixed numeric variant ordering, NULLs, entity identity, duplicate selection and actual native scan-predicate-projection-aggregate execution with publication diagnostics. Fresh native correctness smoke validated 916 commands across all 13 workload families, complete outputs, resource failures and snapshots. Counts in the two test selections overlap; they are not a claim of 255 distinct tests. Existing initializer warnings remain; no full-suite or performance comparison was run.
