# A3 异构属性回退与类型迁移实验

日期：2026-10-12。

新增实验 AdaptivePropertyColumn，实际调用固定列准入检查。适用时使用稀疏固定列；不适用时按槽位使用现有实体属性根 codec，保留原始类型、缺失与 NULL。封装只读拥有数据，不暴露可修改字节；替换构造新对象，类型变化触发编码切换，恢复同类型后可以回到固定列，原对象不变。

新增测试验证整数到长字符串的回退、删除后的固定列恢复、失败替换保留旧值、NULL 与缺失、行边界与编码字节上限。五个限定模块共 70 项测试通过，日志与 JSON 在同名 results 目录。

本对象是实验内存载体，槽位编号和 token=1 仅为内部 canonical 包装，不是权威实体定位。编码字节上限只限制最终载荷与累积载荷，不覆盖单值编码瞬时分配、输入值、容器容量、解码与替换缓冲区，不能宣称统一内存预算完成。回退目前复制整列，并会为缺失槽位编码空根，尚需成本选择、共享页、持久化 descriptor、真实 owner 路由和原子迁移回收。拒绝的逐列 LargeValue 生产载体仍未采用。

进度保持 S0 25%、S1 14.3%、S2–S6 0%、总体 2/34（5.9%）。未运行全量测试或 benchmark，未提交或推送，未修改正式数据库文档。
