# A3 镜像校验流式计算与取消

日期：2026-10-12。

decodeImage 使用现有 updateCrc 分段计算，checksum 字段由四字节栈上零值替代，后续按最多 65536 字节分段。不再为外层 CRC 分配完整镜像副本，字节格式不变。可选存储 CancellationCheckpoint 在入口、每个 CRC 块、每行处理和重新编码前后检查，异常不修改源字节。

新增 150000 字节字符串往返测试，并逐个取消所有实际触达的检查点，验证异常、精确停止和源镜像不变。既有有效 CRC 结构损坏测试继续通过，五个限定模块共 77 项测试通过，同名 results 目录保留日志、JSON、源码 hash。
