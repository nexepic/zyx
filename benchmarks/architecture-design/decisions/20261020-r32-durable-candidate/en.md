# R3.2: durable candidate commit and reopen

This round connects actual persistence rather than adding another standalone planner. Acceptance remains 13/24 (54.2%): complete bidirectional writes, reclamation and comparison are unfinished. No commit/push, full unit suite or new performance timing.

The explicit `publish_candidate` request in isolated format 32 enters the existing native transaction/typed metadata writer. Metadata authenticates actual sources under the same database/generation pin; callers provide no authoritative source, PageIds, assigned physical positions or planning callbacks. Default requests retain the no-write preparation probe. Default production format 31 keeps this feature disabled.

Actual group/column/extension and final fixed-directory B+Tree frames are written to pools reserved by the same batch. Allocator, Catalog, Page Directory, Index Root Directory, ROW authority removal and the nonempty descriptor become reachable in one final A/B publication. Physical frames precede recoverable metadata roots. Only the internal field mode accepts POK_HYBRID_PROPERTY in the pool writer; generic standalone allocation/replacement and descriptor publication remain rejected.

Source ROW pages also coalesce by actual PageId and COW only converted root-slot deletions. Unrelated owners retain exact bytes, slot locators and logical PageIds. New physical ROW frames replace the current mapping, while old pins retain original ROW frames. Directory erasure alone does not leave orphan current ROW records. Empty cleaned ROW pages currently remain mapped; reclamation and space savings are not claimed.

Experimental nonempty descriptor reads authenticate field roots against the pinned actual Index Root Directory/namespace and field/entity identity, without fallback to ROW on failure. Descriptor shape rejects field namespaces without group/owner roots. Global RelocatableIntegrityScanner now verifies hybrid directories plus exact reverse ownership of every current physical field frame, alongside ordinary ROW slot-directory correspondence. Native bodies do not join its database-sized retained raw-page collection. Explicit protected scanner accounts retain their owner; legacy calls without an account retain their existing default-resource convention.

A durably installed candidate is currently a **read-only prototype**. Under the writer lock, unadapted writes/reclamation fail before physical mutation. Nonempty final publication also needs metadata-private batch authorization, preventing generic-root bypasses. Default-format writers retain the original direct path without an admission callback. Complete field writes, inverse conversion and retirement need their dedicated writer route before this restriction can be relaxed.

Fresh independent LargeValues fail before file writes because content-index/global reclamation integration is unfinished. Authenticated existing single-field values may be reused with their existing manifest/content-index mappings. Retained ROW carriers, physical frames and pools must count toward later full costs and retirement admission.

Eleven relevant modules pass 220 default cases and 323 experimental cases, with one format-conditional skip. Final raw JSON/logs and source/binary hashes are included. Integration checks cover dense columns/sparse extensions, actual transaction commit and ROW authority removal, read-only reopen/old pins, partial/full inactive A/B recovery, cancellation after one physical pool with refund/retry, preserved owner65 sharing a source ROW page, propertyless live groups, global integrity, valid-CRC namespace substitution/refund/restoration, fresh-value refusal and existing independent LargeValue reuse/content checks. Existing snapshot/shared-pool/metadata-validation/public-transaction/integrity-corruption modules also pass. No full suite.

The failed build log is retained. Final small adjustments retain the normal writer fast path and instantiate hybrid scanner state only when a descriptor exists. Linux x86_64 only; no cross-platform, full-cost or performance acceptance is claimed.
