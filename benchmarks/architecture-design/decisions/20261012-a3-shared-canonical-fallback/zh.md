# A3 canonical 回退的局部载荷更新

日期：2026-10-12。

AdaptivePropertyColumn 的 canonical 根改为拥有不可变字节的 shared_ptr。更新前后均为 canonical 布局时，仅目标槽位重新编码，其他槽位共享已有根；插入、删除导致的 rank 改变不改变未触及根。布局转换仍通过完整重编码完成。canonicalRoot 返回只读拥有引用，用于检验共享和旧版本保留，缺失槽位或固定布局返回空引用。

新增测试直接验证未变化根的指针身份、变化根独立、NULL 删除、缺失插入后的 rank、失败更新保留旧值及旧引用持续有效。五个限定模块共 72 项测试通过，日志、JSON、源码 hash 在同名 results 目录。

本次减少的是实验对象中的重新编码和载荷复制，尚不是持久化页级 COW 优化。布局选择仍会读取并解码整列以判断是否恢复固定布局，目标值编码瞬时分配与全部内存预算、取消未闭合。容器和引用开销需要纳入完整成本验证；权威路由、持久化迁移与回收仍未实现。

进度保持 S0 25%、S1 14.3%、S2–S6 0%、总体 2/34（5.9%）。未运行全量测试或 benchmark，未提交或推送，未修改正式数据库文档。
