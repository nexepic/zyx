# A3 固定列类型准入检查

日期：2026-10-12。

实验稀疏固定列新增 canEncode，直接检查最多 64 个值，不分配编码缓冲区。缺失和 NULL 不决定类型；其余值必须是同一种整数、浮点数或布尔值。字符串、复杂类型、混合类型及超过槽位上限的输入返回不适用，不做隐式类型转换。持久化数据的校验与异常行为不变，不能用布局回退掩盖损坏。

新增模块测试覆盖整数列变为布尔、浮点和 16000 字节字符串的情况，并用现有实体属性根 codec 验证这些值能够原样往返，包括缺失和 NULL 的区别。恢复同类型后重新满足固定列准入条件。

五个限定模块共 69 项测试通过。构建日志、测试日志和 JSON 复制到同名 results 目录。该证据只证明类型选择与现有编码的可表示性；尚未实现异构布局的自动回退、原子迁移、权威路由及回收，不能宣称 A3 已完成。

进度保持 S0 25%、S1 14.3%、S2–S6 0%、总体 2/34（5.9%）。未运行全量测试或性能 benchmark，未提交或推送，未修改正式数据库文档。
