# 原生过程缓冲区数组归属

私有过程行数组和两个排序堆使用保留所有者的分配器。批量 ID、消费者计数及表达式指针数组在分配前申请额度。旧 const-vector 参数继续借用，没有公共 API 或公共容器表示变更。行内字段与缓存负载独立计费，不能把外层向量的准入等同于嵌套负载已准入。

243 项相关测试通过。新增低额度案例在属性读取/复制前拒绝，异常后归零，恢复额度后可返回三个精确值；属性准入回调观察到仍存活的行数组费用。使用 ce2b467a 的旧过程翻译单元、当前其余依赖进行对照，同一测试失败：旧实现读取一列、复制三个值，仅有 8 字节费用，而行框架至少需 840 字节。此对照不是完整旧源码重建。未执行全量单测或性能测试；S5.3 在嵌套负载归属与验收复核完成前保持进行中。
