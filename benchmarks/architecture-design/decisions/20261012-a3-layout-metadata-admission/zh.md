# A3 布局候选元数据预准入

日期：2026-10-12。

候选构建先核算额外元数据和 owner 表，再按剩余字节预算编码成员目录；仅长度超限导致原布局回退。候选元数据已经不小于原根时提前返回，不继续构建列载荷和共享页。身份、owner/成员错误仍由最先执行的目录验证抛出，不能被成本回退隐藏。

新增精确原根预算、SIZE_MAX 额外成本无溢出回退、原根自身少一字节失败和非法 owner 不被回退掩盖测试。五个限定模块共 92 项通过，同名 results 目录保存日志、JSON 与源码 hash。

这里仍为 codec 字节准入，不是统一分配预算；候选格式和真实身份路由、迁移发布及回收尚未完成。进度保持 S0 25%、S1 14.3%、S2–S6 0%、总体 2/34（5.9%）。未运行全量测试或 benchmark，未提交或推送，未修改正式数据库文档。
