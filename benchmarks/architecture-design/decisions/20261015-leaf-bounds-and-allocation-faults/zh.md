# 解码叶页边界及独立分配故障

本记录仅为组件实现，已验收仍为 22/34（64.7%），本轮指定五项没有新增整项验收。

只读 Catalog/位置目录归属校验使用首尾 ID：编码器保证 ID 严格递增，`(id-1)/capacity` 单调，故检查两个极值等价于逐条检查所属叶序号。可变 COW 页仍保留全量扫描，可见性/类型/CRC/代际校验继续执行。元数据路由单点查找改为先检查整个叶页 ID 范围，再二分查找，不能因先命中前部而漏掉后部错误 ID；更早拒绝损坏尾部的变化已写入双语原生存储规范。新故障用例在请求记录自身有效时分别破坏首尾条目。

独立工作进程增加了按第 N 次全局 new/new[] 请求单次失败的模式，覆盖对齐及 nothrow 形式，不替换生产或基准程序的分配器。固定属性事务正常暂存路径有 6 次分配、正常提交路径有 3,769 次，均在新进程中逐一拒绝验证。暂存失败保留先前语句；提交错误状态及读写重开后只能看到完整旧/新属性集合，并通过完整性检查。“穷尽”仅指这些固定正常操作轨迹，不代表引擎所有工作负载或错误处理分配。

另一个子进程创建查询临时空间后以 std::_Exit(87) 退出，跳过全部析构。新物理只读进程必须将孤儿视为不健康、拒绝新临时空间且整文件 SHA256 不变；读写重开必须回收孤儿、保留用户节点并复用单段临时空间额度。原有 4 项 OOM 回滚/终态保留测试也通过。

验证：1,216 项定向测试、51 个套件通过；6 个暂存故障点、3,769 个提交故障点、4 项原有测试及 1 项崩溃恢复流程，共 3,780 项不同故障/保留/恢复案例通过。未运行全量测试或性能测试，本批排除两项耗时原生排序集成用例。归档含源码补丁/未跟踪源码、准确配方、全部故障序号及最终 XML。

剩余包括完整写变更/属性/撤销/覆盖层/COW/提交工作区、未结租约元数据、计划 IR/解析/编译/Driver ABI、维护预算/推进/积压、分区哈希/聚合溢出、多工作负载完整故障/长稳验收及最终 Kuzu 对比。本固定事务验证不代表性能胜出或完整 S5.4 验收。
