# 可选且有界的计划缓存

组件证据，仍为 22/34（64.7%），不新增阶段验收。

冷缓存按需构造状态，首次插入全部完成后再发布；失败候选连同容量一起释放。资源域重建及插入的预算拒绝不应成为查询的必要依赖：引擎仅对缓存边界的资源准入错误退回不缓存执行，不吞 bad_alloc、语义、损坏或源 QUERY 拒绝。没有活动调用方分配作用域的直接 get 使用缓存 owner 约束逃逸克隆；Native 引擎 get 在 QUERY 作用域内，继续使用调用方额度。

受管后端若不提供共享缓存 owner，自动缓存禁用且清理旧状态，防止缓存把私有 QUERY 账户保留到 64 个活动账户上限。96 轮不同查询编译与释放回归验证没有账户累积。独立 mock 预算压力测试检查满缓存下编译仍成功、旧条目保持、压力解除后可重试插入；它不宣称所有 Native 读取都能在 CACHE 零余量下运行，必要读取仍可拒绝。

694 项相关模块测试通过；871 个独立案例通过，含 32 轮崩溃/物理只读检查/恢复。较短路径穷举，较长路径各抽样至多 96 个分配点；详细数量在 proof.json。所有 source/fault 证据冻结在本目录。动态容器及其他预算闭环仍待继续，没有全量单元测试、新性能基准、RSS/Kuzu 收益或 macOS/Windows 运行结论。
