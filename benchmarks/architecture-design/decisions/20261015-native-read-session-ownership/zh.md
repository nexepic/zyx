# 原生读取会话的分配归属

本记录仅为组件实现：已验收仍为 22/34（64.7%），没有新增交付验收。

原生快照/会话对象、缓存索引与 FIFO 队列、标签缓冲区及所有保留的令牌名副本现归入共享文件缓存预付额度。已有会话的适配器调用不再构造无用的备用会话；独立读取和邻接游标继承快照的分配域。对象前缀在构造失败及经普通多态 unique_ptr 销毁时维持资源生命周期。

协调模式的属性缓存改为保留规范编码的 PMR 字节，不再保留未归属的嵌套 PropertyValue 堆。映射排序工作区使用同一资源，编码失败恢复原有目标前缀。未协调接口保留原有缓存契约；解码返回值仍需调用方/输出准入。缓存保留时编码、命中时解码会改变 CPU 成本，最终性能测试前不声明性能收益。

接管模式定义及嵌套字符串前按已审计的容量上界预留额度，保守计入短字符串内联容量；该额度不是 PMR 实际分配测量或 RSS，也不通过分配重复占位缓冲区模拟计费。替换先销毁旧载荷再退还旧额度。普通自定义 PMR 资源无法为已有外部缓冲区预留额度时跳过此可选缓存。源模式解码及参数构造的工作区仍需单独处理。

槽页及共享池读取副本保留分配域，池读取和属性游标保留页绑定快照额度。读取准入排除已经归属资源的页缓冲区，避免查询重复计费；未归属的临时副本继续执行准入。移除了一份借用页路径上多余的向量复制。完整性扫描保留的页载荷继承来源资源，完整扫描工作区及维护资源类别仍待补齐。

验证：1,069 项定向测试、51 个测试套件全部通过；4 项独立事务 OOM/终态保留测试通过，关闭后的事务对象均保留 1,408 字节。本次排除了两项耗时的原生排序集成用例，仍包含外部排序/算子模块测试。未运行全量测试或性能测试。归档含 XML、准确配方/过滤条件、构建日志、源码哈希和故障证据。

剩余包括解析/编译及原生计划 IR、写暂存/撤销/覆盖层/COW、维护与恢复工作区以及缓存被固定时的推进保障、分区哈希/聚合溢出、Driver ABI 值/序列化、完整故障/长稳验收及最终 Kuzu 对比；本批测试不等于完成 S5.3/S5.4/S5.5/S6.1/S6.3。
