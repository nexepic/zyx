# 向量搜索请求、工作区与输出归属

原生过程为索引名副本和转换后的浮点向量保留额度，直至不可变的公共请求释放借用缓冲区。图投影名称继续保留拥有额度的表示。MSVC 调试代理的重叠分配独立预留。原生搜索的候选数组、距离表、前沿队列、去重表及 PQ 页集合使用调用方分配作用域。事务叠加层命中累积和返回命中数组保留分配所有者；旧 const-vector 借用兼容，公共 Driver ABI 不变。本次不宣称完成旧页面读取/delta 扫描兼容临时数据的准入。

18 个 suite 的 295 项相关测试通过，覆盖原生向量 DDL/搜索/维护、向量表达式、缓冲、原生资源生命周期及 GDS。新增两项验证克隆拒绝、独立复制、移动后复用、逃逸结果生命周期，以及精确搜索观察到的全部 215 个申请点失败后的完整退款/重试、精确节点 ID 和后端关闭后的输出保留费用。生产额度与算法未改变；无全量单测或性能测试。S5.3 当前继续核实过程行内字段和缓存负载的分配归属。
