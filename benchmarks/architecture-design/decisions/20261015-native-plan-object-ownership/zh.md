# 原生计划对象及缓存资源归属

组件证据，仍为 22/34（64.7%），不新增阶段验收。

逻辑算子对象通过拥有资源的分配前缀保留额度，构造失败退款；正常 polymorphic unique_ptr 销毁不需要调用方保持作用域。公开 buildPlan 创建有界 QUERY 账户；execute 在编译前绑定调用方账户，计划节点与后续执行共享总额度。缓存命中产生的私有节点同样受 QUERY 额度约束，返回结果前计划节点退款；逃逸计划继续保留额度直至最后节点销毁。

原生后端提供同一 CACHE owner。PlanCache 状态、文本、索引和克隆的算子对象接入共享 CACHE grant。资源域更换先完成新状态构造，拒绝不改变旧缓存；旧状态释放后才退款。clear 释放容器实际保留容量但保留预算权威，后续插入不能退回普通分配。引擎显式生命周期 reset 额外释放 owner；Database.close 已调用该 reset。4 个原有测试把“仅关闭后端”视为全部缓存已经释放，现明确检查缓存仍持有额度，并在 reset 后保留原有归零断言。

索引借用 LRU 条目拥有的查询文本，删除前先移除索引。8192 字节查询的文本级 PMR 分配由两份变成一份；重哈希、更新、调用方修改和淘汰用例验证视图有效。原有 >2000 字节保留断言依赖重复文本，现按一份 1000 字节文本及其元数据检查 >1000 字节，额外独立探针严格断言只分配一份文本。

解析器保留资源拒绝、局部额度拒绝和 bad_alloc 的类型，避免包装错误消耗新内存或把资源错误变成语法/计划错误。590 项相关模块测试与另外 12 项 Database 生命周期测试通过。最终索引版本通过 100 个独立案例（25092 个正常缓存未命中分配点中抽样 96 点）。此前版本通过 868 个独立案例和 32 轮崩溃/只读检查/恢复；其源码只在生产索引键类型上不同，保存了该历史头文件，不能当作最终版本全部重跑。

没有运行性能基准。上述数量不是时间或 RSS，不声称超过 Kuzu，也不声称另两平台运行通过。标准 IR 内部字符串/容器、表达式及其他私有工作区仍待接入，不能把算子对象计费当成整个计划堆都已治理。
