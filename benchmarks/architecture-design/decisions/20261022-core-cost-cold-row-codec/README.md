Cold rows reuse canonical ROW bytes or existing owner-keyed whole-root LargeValue references. Each block caps decoded payload at4096bytes and rows at64. Store RAW or strictly smaller existing LZ4, respecting the original slotted-record size; split rather than increase limits. Exact stored/uncompressed CRCs, expansion size, owner/type/generation, canonical ROW directories and census are checked before returning decoded storage. LargeValue reference structure is not actual manifest/media/content/count authentication. Cancellation, quota failures and output-lifetime ownership refund the original account. Location bindings use the uniquely shorter dense16bytes/owner or grouped24bytes/distinct-block representation, with dense ties, exact disjoint masks, canonical empty unused references and exact slot generations.
