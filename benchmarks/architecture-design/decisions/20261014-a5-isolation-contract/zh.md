# A5 隔离与冲突合同

日期：2026-10-14。范围：S1.5 设计交付。细粒度生产验证、S5.1/S5.2 和性能验收另设门禁。

## 承诺的并发结果

原生逻辑图承诺固定快照读取、保守的乐观写验证和原子持久发布。普通事务可读取自己的暂存覆盖层；只读事务在后续提交后仍保留原成员和值。同一可写后端内部串行发布。本合同不宣称所有 API、过程、模式操作、独立可写句柄或进程均具备可串行化隔离。批量会话文件租约不能证明普通发布门跨句柄共享；应用须使用一个可写数据库所有者。跨所有者发布需要独立所有权协议和测试。

多个普通写事务可基于同一快照暂存。修改图的提交使另一个写事务的图 fence 失效，即使二者修改不同实体。冲突事务进入终态，重试须创建新事务并重做读取。只读完成允许存在中间提交；其他快照看不到未提交修改。禁止脏读、丢失更新、悬空边以及本次 write skew 案例的双方均提交。流式 bulk append 不提供普通覆盖层的读己之写，其有界 ID/暂存预留和发布保持原路径。

## 当前验证与成本

`makeLogicalGraphMutationFence` 验证数据库/格式身份以及七个根的物理帧、槽和 generation：Node、Edge、属性、大值清单、向量位置、向量清单、状态目录。比较为固定大小：21 个根字段加身份。纯分配器元数据发布不必使 fence 失效。索引根目录和页目录不在其中；因此未来属性通过稳定逻辑页 COW 时，必须同时推进语义属性根或已纳入 fence 的状态目录，仅更改页目录映射不足以使图写入可见。

属性源验证发生在最终规划之前；修改执行器在发布时再次验证预期 fence，并按适用的当前目录校验约束。不能仅由图 fence 推断并发 DDL 一定冲突。当前没有独立 schema epoch，须保留保守绑定身份和当前约束校验。约束失败与逻辑冲突是不同结果。候选规划和 IO 成本仍随受影响页、值、索引和邻接增长；固定大小 fence 不代表固定时间提交。

## 目标验证键

首版细化协议采用实体版本，不采用独立字段版本。记录 `(实体种类、逻辑 ID、生命周期/属性/标签版本)` 的读写依赖、端点存在性、唯一键成员、范围/谓词/索引语义 epoch、邻接成员和 schema epoch。同一实体的不同字段仍可冲突。不存在的读取也记录缺失依赖；创建 ID 通过租约分配且不复用。索引根 generation 不变不代表语义不变，叶页 COW 需要显式 epoch。不支持的谓词、未跟踪过程和不完整依赖集保留整图 fence。在每条路径均记录依赖或采取保守回退之前，不得放宽生产 fence。

发布门内对最新状态验证。写事务须同时验证读取和写入；仅验证写集合会允许 write skew。事务重新开始后，唯一性验证仍须检查最新约束/索引成员。端点删除和边创建通过端点生命周期依赖冲突。范围插入使谓词 epoch 失效，包括空范围观察。模式变更须重新绑定或拒绝；追加 token 不自动等于语义 DDL。版本溢出在发布前失败，新增持久版本字段先通过 A7 兼容和恢复审查。

依赖内存增长前计入查询/写账户。R 个实体依赖、P 个谓词/模式依赖、W 个写入及 C 项约束的验证为 O(R+P+W) 次认证查找加实际约束工作 C；树深和 IO 单独报告。有界依赖准入可保守回退旧 fence，不能丢弃依赖后继续乐观提交。指标区分逻辑冲突、物理重建、回退原因及重试耗尽。

## 逻辑独立与共享物理页

两个逻辑独立实体可能同处一个 COW 页。旧页候选不得覆盖已发布的邻居修改。逻辑验证成功后，从最新固定根重建受影响共享页、目录路径和派生索引，仅应用已记录写意图。大值引用通过最新认证清单解析；物理 owner/generation 校验仍保留。首版最多构建三次候选，持续发布竞争时拒绝；每次尝试均重新验证依赖。在实现及验证完成前，保持当前保守拒绝旧候选的行为。冲突实体的读改写值不得直接重放到最新值上。

## 重试、取消与不确定提交

逻辑冲突释放暂存所有者/快照 pin，并放弃未完成 ID 租约；允许 ID 间隙。重试指完整新事务及新读取，不能对终态对象再次 `commit()`。引擎不得自动重放带外部副作用的用户查询、CSV 回调或过程。内部候选重建不包含这些回调，且保留取消/资源准入检查。确定回滚允许新事务；持久写结果不确定时封锁后端直至关闭/重开恢复，先检查完整恢复 generation 再决定应用级重试，不能重复确认不确定提交。私有页回收和租约清理遵守现有快照 pin 与资源计费。

## 双事务证据与替换门禁

| 交错 | 当前观察结果 | 细化协议必须满足 |
|---|---|---|
| 双方读取两名在岗医生，各关闭一名 | 首个提交，第二个冲突；固定读者仍见双方在岗 | 验证双方读依赖，禁止均提交 |
| 写者统计范围，另一事务插入，前者据此写摘要 | 原成员保持稳定，派生写冲突 | 谓词 epoch 或整图回退 |
| 暂存边后另一事务删除端点 | 删除提交，边冲突，无悬空发布 | 端点生命周期验证 |
| 两个写者暂存相同唯一键 | 首个提交，第二个冲突；全新重复重试仍约束失败 | 最新唯一成员及模式验证 |
| 两实体共享属性页，各自修改 | 首个提交，旧第二个冲突；全新重试保留两者，重开一致 | 最新页重建或保守拒绝 |

五项新增原生模块测试实现上述交错，包括真实相同 page-ID/不同 slot 断言及完整性校验；同时选择相关事务验证、原子性/故障模块回归。这些测试验证 Linux 单后端的具体历史，不证明所有历史或跨平台/进程并发。S5 接入前须补真实并发线程、缺失/标签/邻接/DDL 依赖、有界重建饥饿、资源/取消和每个发布步骤故障测试。O6/O7 对照留到最终性能窗口。
