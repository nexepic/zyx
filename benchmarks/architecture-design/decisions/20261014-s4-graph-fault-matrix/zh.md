# S4.3 验收

接受获准的仅键树/主记录路径的图语义与故障验证。新增真实原生生命周期历史验证平行边、自环、双向邻接、暂存 overlay 的删除/创建、原子发布、旧会话重复读取、新快照、完整性及重开。事务基础快照保持固定，读己之写通过 LogicalGraphTransactionOverlay。候选有效字节不一致测试不冒充生产破坏测试。

208 项相关矩阵包含邻接 codec、范围/续读/缓存/overlay 合并、页后端适配器、有界原生会话、权威完整性破坏检查，以及原生事务发布故障（短写、ENOSPC、元数据、根、同步）。现有完整性测试拒绝有效编码下的遗漏成员、错误端点、外来 owner，以及 sibling/separator/restart 破坏。原生 trail 验证保留平行边、自环并禁止重复边。未启用覆盖格式，不宣称硬件断电模拟；S4.4 基准仍待完成。
