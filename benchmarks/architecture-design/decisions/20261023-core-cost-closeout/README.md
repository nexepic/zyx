# 本轮收尾记录：实现冻结，P7 未通过

本轮已停止扩展实现并完成最终统一测量；**验收仍为 90%，不是全部优化完成或 Kuzu 目标达成。** 前向冷转换／完整目标构建与全库空间准入仍未交付，公开入口保持关闭，不以私有夹具或 8 组前缀绕过门禁。当前结果基于真实默认格式生产路径，不使用未采用的实验布局制造收益。

## 已完成的固定清单工作

- 跨组／混合 Node、Edge 的冷热修改共用一套私有 FieldPage，合并 namespace 目录后一次原子发布；包含混合创建、删除、整列降级、逻辑 API、旧 pin／integrity，以及全批超过 64 实际变化或迁移 owner 的写前拒绝。
- 修复 4096 字节缓存的完整查询：单帧顺序扫描使用原有有界复制路径，不把唯一帧的 pin 留给后续消费者或换页；不增加缓存额度或减少校验。保存修改前的失败报告与异常栈。
- 必要模块验证：实验两种 membership 配置各 564 项、默认 154 项、缓存两种额度的完整查询 2 项均通过；每个实验报告包含 27 项持久化生命周期用例。没有执行全量单测。

## 最终性能

99／99 独立进程全部通过语义 oracle。每类查询／写入 3 个独立进程、每进程 3 次预热＋10 次正式测量；每数据集导入 3 次。下表为正式计时 P50（毫秒），不含排除在合同外的准备／核验；完整进程墙钟另列在资源表。

SET 约提升 12.9–14.0 倍，1000 边批写约提升 12.2–12.4 倍，导入约提升 6.3–6.7 倍。过滤／分组仅约提升 1.2 倍，仍有数量级差距；六个核心场景在两个数据集上均未达到等价 Kuzu P50。两个数据集的过滤／单键分组没有达到原定 5 倍结构性门槛。所有既定回归守护的 P50/P95 均在 5% 退化线以内。

Kuzu 生产 COPY P50 为 medium 887.417 ms、holdout 784.591 ms；ZYX 分别慢约 46.4／42.9 倍。这与等价 1000 行提交边界对照不同，单独展示，不以较好的一项代替另一项。三个导入样本的最大值不是可靠 P95。
