# 私有读取的受保护复制

组件实现证据，整项验收仍为 22/34（64.7%）。overlay 从已有字段产生私有副本时，在复制前为嵌套载荷申请额度；显式读取回调路径保留取消检查。标准字符串按最终大小构造，哈希表预留包含浮点舍入余量，复制估算与实际构造使用相同策略。递归复制上限为 64，直接 Map 复制也计入根层级；超深拒绝不修改源对象。

170 项相关模块测试通过。98 个独立案例通过，包括混合补丁正常路径全部 90 个分配点逐个注入失败。受保护复制探针覆盖 18 种形状（含稀疏/高负载表、嵌套和字符串容量边界），未发现未计费分配；解码和中途取消探针继续通过。这些是正确性和分配请求检查，未运行性能基准，也不代表 RSS、macOS 或 Windows 的运行证据。

其他编译器/IR、目录工作区和稳态资源验收仍待完成，不把组件记成阶段验收。
