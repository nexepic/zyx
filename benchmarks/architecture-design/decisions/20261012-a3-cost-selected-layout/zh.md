# A3 基于完整候选编码成本的布局选择

日期：2026-10-12。

新增实验 PropertyLayoutCandidate，验证 owner/成员关系后构建原根与紧凑页候选，计入 owner 表、成员目录、共享页及调用方明确提供的额外候选元数据字节。候选必须严格小于现有根且满足字节/页数边界，否则保留原根。异构/非固定类型与单列超页也回退。返回 Image 仅保留选定表示的属性载荷，不保留两份可独立读取的属性副本。

新增共享字段选择 2224 字节候选、独有字段保留 3456 字节原根、增加元数据后改选原根，以及混合字符串回退并原样解码测试。五个限定模块共 91 项通过，同名 results 目录保存日志、JSON 与源码 hash。

这是 codec 成本选择原型，不是生产优化器或自动迁移。额外元数据参数必须真实计入调用方 descriptor/引用成本；传零仅用于结构实验，不能当生产准入。候选构建同时占用临时对象，统一内存预算及取消未接入；行数/字段/目录和页数只限制逻辑工作量。格式身份、权威路由、转换发布和回收仍待完成，空间选择也不证明扫描和更新性能。
