# 表达式对象及共享控制块归属

组件证据，仍为 22/34（64.7%），不新增阶段验收。

表达式独占对象使用资源前缀，标量字符串在复制前准入。AST 构造、语义分析、计划构造及逻辑算子克隆中的共享控制块通过拥有分配器计费；少量 make_shared 创建改用拥有分配器的 allocate_shared，避免跳过类级 new。独占指针转共享指针时，控制块拒绝会恰好销毁一次已消费对象。构造失败退款；资源保持到最后所有者释放。旧调用忽略无关环境默认 PMR，保留普通全局分配行为。

字符串构造完成后按观察到的容量缩减保守上界，仅退款不追加申请；自赋值不复制。原查询头文件的传递 include/命名空间别名仍保留。686 项相关模块测试通过，含控制块失败、构造失败、作用域结束后的存活、跨资源表达式克隆以及表达式克隆/访问器回归。

106 个独立案例通过，包括缓存未命中路径 96 个分配抽样点，以及六种固定子存储表达式的实际克隆/控制块分配探针；没有观察到漏计，销毁后存储和额度归零。字符串、codec 与中途取消探针继续通过。表达式渲染属于另一个调用方拥有的 API 操作，不在此克隆探针内。动态参数向量和嵌套 PropertyValue 字面量仍待治理，不能把这六种形状当作全部表达式堆都已计费。

运行平台为 Linux/clang19/libstdc++14；未运行性能基准，不报告 RSS/Kuzu 提升，也不声称另两平台运行通过。
