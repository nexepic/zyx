# A2 仅为持久目标预留替换槽位

日期：2026-10-12。

创建补丁已折叠进创建载荷后，适配器仍按所有 patch 数量 reserve 完整替换数组。现利用请求校验阶段累计 persistedTargets，仅对这些目标预留槽位；源 shaped admission 的能力判断也复用计数，不再额外遍历 patch 列表。计数受已准入的 patches 数量约束；追加容量仍检查 size_t 加法溢出。创建专用批次不再为不会产生的替换预留空间。

严格模块构建及 17 项相关测试通过，包括真实 native 创建重开、大值快照/失败重试和 adapter 的创建/持久混合引用。未新增镜像实现的容量测试：标准容器实际 capacity 可以大于 reserve 请求，不能以请求值断言精确分配。该修改不等于统一预算完成，未测量性能收益。

证据位于 results/20261012-a2-patch-target-capacity，含日志、JSON、源码 hash。仅 macOS 验证；未运行 benchmark、全量测试、提交或推送，未修改正式文档和英文记录。S0 25%，S1–S6 0%，总体 1/34（2.9%）。
