# A3 紧凑固定列子块

日期：2026-10-12。

新增 CompactFixedPropertyColumn，24 字节子块头：kind uint16、rows uint16、reserved uint32、presence uint64、nulls uint64；后续仅实际非 NULL 载荷。无独立 magic、version、CRC 或身份字段，必须由外层可信页格式提供这些保障；不能直接作为可独立认证的数据引用。当前共享页 v1 尚未接入这种子块，不改变其含义。

与完整 Adaptive 固定列镜像相比每列减少 56 字节头部。解码暂以至多 560 字节的独立固定列临时镜像复用现有严格 validator 与批量读取，保留类型、mask、长度和布尔验证。新增末槽位、NULL、整数、负零、布尔往返以及类型/行数/保留字段/null mask 损坏拒绝测试。五个限定模块共 87 项通过，证据在同名 results 目录。

该 codec 为下一版共享页提供紧凑载荷候选，尚未证明包括 owner 路由、成员目录及生产页元数据后的总成本。独立镜像共享页的稀疏拒绝结论不变。仍需明确外层版本、身份、子块 tag、异构回退、预算、发布与回收。

进度保持 S0 25%、S1 14.3%、S2–S6 0%、总体 2/34（5.9%）。未运行全量测试或 benchmark，未提交或推送，未修改正式数据库文档。
