# 单窗口物理字段页复用

S2 未验收，进度 15%。同一列/冷值预检窗口可复用一个已认证物理字段页，读取组、成员矩阵和列记录；绑定原快照并在 IO 写入纪元或读取模式变化时重取。仅保留同步窗口内一个页，不增设持久缓存。固定游标记入源工作区，冷值解码前释放不再需要的物理页。逐槽、owner、类型与记录验证保留。

12 项隔离读取/查询用例、1 项默认拒绝用例及 8 项 13/39 字段复用回归通过。真实类型化批 API 的复用计数为正；资源预付边界注入物理页损坏后，在输出值前重新认证并拒绝。兼容模块另覆盖旧 pin、取消、重入、缓存压力、NULL/布尔/浮点位与游标移动。精确结果、源码和核心库 hash、构建/编译/链接日志见 receipt.json 及附件。

首轮测试误用了非批量 scalar API，无法覆盖目标窗口，失败日志保留；已改用生产所用 typed batch 参数。修改最后一个冷值释放点后中止中间编译，三配置最终构建及新鲜模块对象覆盖该次中间结果。没有运行查询基准或全量单元测试，没有提交推送。完整更新、标签回退、真实两库空间/资源与最终性能门槛仍待完成。
