# ROW 分块压缩候选

宽属性超时诊断确认，小字段更新仍会物化所在行的大值载荷。此候选在已有 ROW 分块页成本准入通过后，尝试已有 LZ4 不可变分块编码；沿用原 5% 最低压缩收益、RAW 回退、分块边界和页成本门槛。仅在编译支持 LZ4 且允许 RAW 回退时选择；显式编码/边界策略及关闭自适应策略时的行为不变。不新增布局、格式或 Driver ABI，也不提升资源或时限。

49 个必要模块的 680 项测试通过，含 3 项新测试，验证显式/严格 RAW 策略、可压缩数据的实际页数和精确值、不可压缩数据的 RAW 回退及页数上界。旧快照、搬迁、回收、故障恢复和类型变化相关模块也通过。未跑全量单元测试。

13 家族 smoke 的 886 次完整检查及同一组 578 次诊断操作通过。诊断中 128 字段/1MiB 载荷的更新，中位写入字节从 2736288 降至 449696；完整诊断文件从 44695552 降至 9830400 字节。两个修复前的静态只读消费者均精确读取新压缩文件的完整 128 字段、大值和动态属性，文件哈希不变。

上述是机制与必要正确性证据，不是正式性能通过。完整 10000 实体动态属性、完整宽属性/大值场景仍必须在原 1800 秒、2GiB 文件、6GiB 地址空间及64MiB查询限制内完成，随后按原门槛评估最终读写/资源窗口。候选冻结待验收，仍为31/34（91.2%），不声明超过Kuzu。
