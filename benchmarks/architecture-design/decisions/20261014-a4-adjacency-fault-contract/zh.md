# A4 邻接权威、候选与故障模型

日期：2026-10-14。范围为 S1.4 设计；普通 Edge record 保持权威，不据此验收生产覆盖邻接或 S4。

## 当前行为与首版接入

普通全局 Packed B+Tree 使用 17 字节 `(direction, NodeId, EdgeId)` 键和空叶值，不覆盖 NeighborId/TypeId。PageBackedGraphReadAdapter 在同一元数据快照读取 Edge record，认证身份并按请求方向核对端点。批次路径有界收集并排序 Edge ID，读取主记录，检查数量、缺失及端点一致性，按原键顺序输出。NativeReadSession 复用绑定精确快照，缓存命中不能作为另一个 generation 的证明。

首版覆盖候选保留主记录验证，采用有界批量读取与认证会话复用。覆盖邻居/type 在输出或因类型过滤丢弃之前须与主记录一致；过滤不得隐藏已遇到的坏 entry。本决策不授权仅凭证书信任、跳过主记录或改变损坏发现时机。后续提案须先同步公开故障合同、格式规范及故障测试。checksum 通过从不证明跨结构一致。

## 故障责任与发现时机

| 故障 | 页/codec 加载 | 原子写者/恢复 | 局部查询与完整性扫描 |
|---|---|---|---|
| 数据/超级块 torn 或 short write | 精确长度、格式和 checksum 拒绝遇到的坏页 | COW 数据先于持久根发布；A/B 恢复选择完整有效 generation；不确定写须重开 | 查询拒绝触及坏页；扫描访问活跃可达结构；checksum/恢复不修复任意损坏 |
| 错 owner、逻辑页或 generation | 认证映射与头/owner/generation 匹配，检查类型/布局/codec | 匹配路由和页共同发布，pin 身份不可被回收复用 | 遇到身份不符报格式错误；扫描还检查外来/不可达/孤儿关系 |
| 覆盖端点/type/Edge ID/方向错误 | 合法字节仍可能表达错误语义 | 创建/删除在一个图 generation 原子维护主记录及双向成员 | 首版输出/过滤前核对主记录；扫描检查所有应有成员及多余 entry |
| 合法页中遗漏成员 | checksum 或 entry 解码无法局部发现 | 正确写者的双向原子维护防止遗漏 | 局部扫描可能少返回而不发现；全图/邻接交叉校验必须拒绝 |
| 缓存/continuation/overlay 身份过期 | 复用前核对精确快照/程序/owner 身份 | 发布失效，旧 pin 保留旧完整布局 | 拒绝外来 continuation；合并暂存增删不暴露部分提交 |
| 越界链接/环/兄弟/restart/separator 损坏 | 核对遇到的边界、布局、owner 并有界遍历 | 写者生成规范结构，搬迁原子更新映射 | 局部检测取决于访问路径，完整扫描覆盖其余路径 |

完整性检查是显式验证，不承诺自动修复。持久发布故障须区别于外部位翻转或生成合法 checksum 但错误语义的写者。不能保证查询发现未访问页或遗漏 entry。全文件扫描也须有界内存、可取消且固定 generation，不能混合并发发布的结构作比较。

## 同一逻辑接口下的两种候选

接口输出 EdgeId、NeighborId、TypeId、方向和快照可见性；continuation 绑定快照及比较器。以下格式为目标，非已存在 codec。

| 维度 | 共享 Packed B+Tree 覆盖 | 共享分段邻接块 |
|---|---|---|
| 路由 | 单全局键空间；u64 叶定位符指向共享定长拓扑块 | 单共享 Node/方向/type 目录指向有界块，多节点共享块/页 |
| 低度数 | 共享叶/块，无每节点根或独占尾页 | 多个低度数节点共享容量，描述符单独计费 |
| 超级节点 | 有界范围扫描及批次主记录读取，分裂限制修改工作 | 有序块链/块 ID 树与有界 continuation，目录分裂限制工作 |
| 覆盖字段 | 定位符解析 EdgeId/邻居/type，认证块/页身份 | 同字段 entry，认证块/页身份 |
| 写入 | COW 受影响叶/拓扑块/目录路径；双向与主记录原子 | COW 有界受影响块/共享目录路径，不整节点重写 |
| 搬迁/回收 | 稳定逻辑页映射、owner/generation 认证、旧 pin 保护 | 同左，原始物理定位符不能跨 generation 使用 |

当前树支持空/u64 叶值，不支持任意覆盖载荷。首候选仅在 A7 分配 codec 并验证页/槽边界后使用 u64 定位符，不得静默重新解释保留的 key-only 树。须使用并行新内部命名空间或显式版本迁移。分段头定义 block ID、数量、owner、generation、排序范围、后续 continuation 和精确 codec。本决策不分配新持久常量。

## 语义、生命周期与替换门禁

平行边保持不同 Edge ID。自环各有一个出向/入向成员，BOTH 方向遵循现有查询去重合同。排序/continuation 使用无符号键序；类型过滤在验证后应用。暂存增删覆盖层按同序合并，每个 continuation 恰好处理一次。实验不新增公开端点/type 修改 API，使用已有创建/删除操作维护。

图发布原子安装主记录、双向派生表示、路由、索引和退役记录。仅改变页映射的候选语义写入还须按 A5 推进已纳入图 fence 的根/状态 epoch。旧快照解析旧路由，pin 或其他共享引用存在时不得回收候选块。退役由可达性证明授权，不能仅凭调用者持有 root 清单或 LVID 差集。恢复不能只发布一个方向。维护搬迁逻辑页时保持身份校验，并计费保留的旧 generation。

S4 原型门禁覆盖点邻居、批量遍历、类型选择率、随机低度数、倾斜超级节点、平行边/自环、overlay、并发旧快照、持续增删、搬迁、稳态空间和有界内存。计量全部路由/描述符/数据/主记录读取和写入，不能仅统计载荷。注入 short write/ENOSPC、A/B torn 发布、owner/generation 交换、合法 checksum 的覆盖不一致、遗漏/多余成员、过期 continuation、pin 保护回收故障。端到端成本不达优化门槛时保留现布局。性能留到最终窗口。

本次选择邻接 codec/index、完整性损坏及原生事务原子性/故障模块作为证据。现有测试明确拒绝遗漏成员、合法 codec 的错端点、外来 owner/generation 和坏树。这是设计/故障证据，不代表覆盖格式已实现或主记录 IO 已消除。
