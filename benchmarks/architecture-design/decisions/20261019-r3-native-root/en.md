This implements the native metadata lifecycle for empty descriptors, not the complete property-subblock deliverable. The fixed five remain R3.2/R3.3/R5.1/R5.2/R5.3, with zero complete; total stays 13/24. This directory records source identity/hashes/patch, build/binary identity and raw selected results.

`ZYX_EXPERIMENTAL_HYBRID_PROPERTY_FORMAT` defaults off. The additional Superblock root occupies 336..351 using existing physical-reference packing; the experimental emergency reserve starts at 352. The builds reject each other's files without migration. Full framing is in R3.1 `r3-layout-en.md`. No nonempty hybrid property capability or new data-pool/page-owner kind is advertised.

The descriptor is an independent physical frame in existing metadata pools, not State/radix, a routed MetadataPageId or a thirteenth logical bootstrap root. Recovery, read-only discovery, reachability, old-pin protection, conservative directory cloning and clear/reclaim explicitly recognize it. Local evacuation encountering the extra physical frame keeps existing conservative fallback. Relocation updates physical generation/LSN while preserving semantic generation. Publication retains data fence → inactive A/B → superblock fence.

The graph fence adds an eighth descriptor member (zero in default files), and the two formats have different format tokens. ID-only classification and blind adjacency rebase cannot ignore descriptor changes. Writers reject nonempty business roots before frame allocation. Read/open/new snapshot/integrity also authenticate and reject currently unsupported routing. Valid checksums do not replace database/physical-generation/LSN checks. Failed snapshot authentication refunds its new pin. Descriptor reads use the file view's fixed database ID, avoiding reads of the writer-rebound routing Superblock identity.

The fixed charged PROFILE registry adds `native_graph.read.metadata_decodes.hybrid_descriptor`, a current-thread cumulative count of attempted descriptor decodes. Registry/result staging bounds derive from actual entry count; resource caps are unchanged. The codec uses fixed 4 KiB buffers. Full cost must include the actual frame, 128 KiB reserved pool capacity and retained old pins, not only 192/224 bytes. A complete native cost estimator is still absent; this does not admit conversion.

Final verification uses separate explicit filters, never the full unit suite.
