# 移动拥有的标量源物化

组件验证；验收进度仍为 22/34（64.7%）。

标量完整属性 Node/Edge 读取现在把本地拥有的原始记录移动到逻辑物化；借用 const 记录的接口继续复制。缓存标签名返回移动拥有的 optional 字符串。Node 重复检查在 PMR 哈希集合中借用稳定输出的键/标签视图，保留哈希算法，避免额外保存名称副本。元数据使用显式所有权作用域或快照分配上下文，无上下文旧读取使用 new_delete_resource。显式临时准入回调继续作为其资源的唯一准入者，避免重复计费；临时资源持有上游 owner 至销毁。

151 项受影响模块测试全部通过。禁用环境默认分配器的用例现同时验证完整 Node/Edge 重读；它发现并修复了早期元数据实现错误使用无关默认资源的问题，没有放宽测试来允许失败。

独立分配探针通过完整原生 Node/Edge 源路径读取 65,536 字节字符串属性，现各请求一次 65,537 字节字符串缓冲区。恢复 const 复制分支的反证构建各请求两次，触发未放宽的断言。此测量是分配请求，不是延迟或 Kuzu 比较。

最终 worker 通过 103 个独立案例，含完整源读取正常 955 个分配点中的 96 个抽样点、四个终态案例及三个 codec/复制探针。bad_alloc 后，同一快照可重试完整 Node/Edge 读取，用户图 fence 不变，完整性通过，关闭后协调资源额度归零。成功负载检查放在异常捕获之外；准入解码堆模型和无分配检查探针仍启用。
