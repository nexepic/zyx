# 表达式向量及列表输入准入

组件证据，仍为 22/34（64.7%），不新增阶段验收。

自持载荷的元素使用拥有预算的标准向量外壳，保留 const std::vector 引用接口。扩容前为新旧 backing 重叠准入，旧 buffer 释放后才转移额度，不退款重申请。外来向量先检查可观察 capacity 再接收，拒绝不移动输入；移动后的空向量保留代理额度和资源，能重用。push_back 的同向量别名在扩容后按索引重新绑定，避免悬空引用。普通字符串/PropertyValue 元素不能假装自持载荷；它们仍需单独策略。

函数参数、动态列表元素及相关构造/克隆/算术临时向量接入。静态列表不再调用 parseListLiteral 再次解析；从已经解析的稳定借用视图为整份载荷取得额度，再一次性构造。Root PropertyValue 的两个向量移动代理在构造前计入，完成后仅缩减。混合类型、嵌入 NUL、第二轮复制中途取消、过大预留和移动别名均有回归。

701 项相关模块、107 个独立案例通过。表达式实际分配探针从六种增加为九种，加入 64 参数函数、动态列表和静态列表；字面量探针的列表路径使用新列表工厂。未观察到漏计，销毁后存储和额度归零。长缓存故障路径仍为 96 点抽样。
