# 事务范围归属与延迟目录上下文

本记录仅为组件实现：已验收仍为 22/34（64.7%），没有新增整项验收，也没有运行性能测试。

普通事务创建范围及预览范围缓冲区现与对象/已分配 ID 使用同一 WRITE 账户，复制显式保留分配器。预览准入失败不会留下空的或半初始化的预览记录；暂存失败保留原预览并可重试。持久 ID 获取后范围准入失败会放弃能力。新增 span 清理接口直接借用已有范围，不分配转换向量，因此继续支持 OOM 回滚。终态重置保留原分配器，不会捕获不相关的外部分配域。流式预留及存储层未结租约映射仍待覆盖。

分配故障定位发现，属性目录的延迟解码发生在创建读取作用域结束之后，原始调用栈显示 MetadataPageRouteLeafCodec::decode 使用默认资源。现可强引用捕获上下文，每次游标推进均恢复快照读取绑定；嵌套绑定、构造失败及线程局部恢复已验证。游标对象和路径向量使用同一缓存额度。没有资源归属的对象前缀使用生命周期永久的 new/delete 资源，避免借用临时默认资源。已验证默认 PMR 完全拒绝分配时的完整属性和拓扑读取。

恢复目录上下文后，可复用解码后的路由页：重复计数读取既不访问磁盘，也不增加 Buffer Pool 命中次数。测试现要求命中计数保持不变，不再要求一次无用的查找；未提高任何测试预算。

验证：1,209 项定向测试、51 个套件全部通过；4 项独立事务 OOM/保留测试通过，关闭对象均保留 1,736 字节请求分配量。未运行全量测试，本批排除两项耗时原生排序集成用例。归档中的失败诊断属于修复前游标，最终 XML 和故障证据均为零失败。
