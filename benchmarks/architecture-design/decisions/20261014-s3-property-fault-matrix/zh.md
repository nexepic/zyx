# S3.4 属性正确性与故障验收

当前源码默认启用的 ROW 放置通过 **9 个相关 suite 的 245 个测试**。选择包含属性/LargeValue/owner/缓存/codec/内容/范围/退役、原生生命周期、完整性损坏及原生事务发布/校验。自 S3.3 检查点后只增加测试和证据，其 916 条原生正确性报告继续适用。未运行全套或计时基准。

新增真实原生故障矩阵写入符合准入的 256 KiB 集合，pin 旧图，注入四个发布故障：公开 LargeValue 数据帧前 ENOSPC；实际写入数据帧前 64 字节后 EIO；实际写入图 Superblock 前 64 字节后 EIO；完整图 Superblock 写入后的最终 sync 失败。所有情况均保留旧 pin 的标量和完整字段体。发布前/撕裂根场景重开后为完整旧图；最终 sync 不确定时，原句柄在重开前拒绝后续写入，恢复只暴露完整旧图或新图，重试成功。恢复后原生完整性检查通过。

独立物理只读后端通过变长 chunk 读取标量/字段体/non-null，拒绝替换，写字节为零，完整文件大小保持不变。已有模块拒绝错误 owner/generation/token/offset、坏规范值、checksum/数据/Manifest/内容不匹配、外来/已释放快照和错误根路由。范围复用、准入的拥有式输出、大值转内联、删除、pin 保护退役、数据搬迁、多级流式物化及未知 media 保留合同继续通过。

验收 S3.4 当前 ROW 布局和属性消费者。不代表 MIXED/列组损坏覆盖或逐属性独立 LargeValue 写入。内存/资源协调、spill、O3/O5 比较和长期维护仍属各自任务。四个注入历史模拟实际测试进程及重开边界，不推断硬件断电持久性。
