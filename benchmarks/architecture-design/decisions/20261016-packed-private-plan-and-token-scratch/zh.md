# 固定配额下的最终输入阻塞修复

大输入在约 52 万条边后触发强制 COW 重建，完整解码的全局邻接叶条目超出 WRITE 工作区。私有规划改用已有规范 packed 叶编码，逐叶解码并复用；虚拟节点用有界计费 deque 避免扩容深拷贝。没有更改文件格式或提高资源上限。10 万键固定 4 MiB 测试、两种布局逐字节页面一致性、异常退款及损坏拒绝通过。

完整正确性合同另发现属性 token 绑定的临时元数据使用 CACHE。解析只返回标量，现在临时缓冲归属现有查询预算；共享缓存发布仍显式归属 CACHE。CACHE 完全占满时的原生 token 绑定和原有 32 KiB 查询均通过。

103 项定向测试通过。最终受影响模块回归、源码冻结和最终输入校验仍在进行；本记录不新增进度或性能结论。只运行必要模块，没有全量单测。

104 个指定模块、144 个套件的 2,202 项测试全部通过。完整合同仍被倾斜聚合拒绝阻塞，精确栈复现正在进行；另一个诊断中倾斜聚合通过，但 10 万个独立分组的完整输出触发 QUERY 预约拒绝。不能将这些失败计作性能通过。
