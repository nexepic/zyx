# A3 原生目录取消传递

日期：2026-10-12。

读取适配器 token 入口新增可选 CancellationCheckpoint，入口及实体存在性验证后检查，再传递给存储目录读取。A3 原型将现有同步 callback 包装为借用 CancellationCheckpoint，生命周期限于同步调用，传递到 codec 校验及复制循环。无 callback 不启用额外虚调用。保留原有预算回调前后取消检查。

新增真实 native planner 快照测试创建 64 字段节点，在第 20 次检查中断（输出准入前），以及第 100 次检查中断（准入后）。验证实际停止次数及准入阶段，随后同快照正常重读完整目录，generation 未变。四个限定模块共 27 项通过，Werror 构建及测试 JSON、源码 hash 保存于同名 results 目录。

本轮贯通的是目录遍历的合作式取消；单次实体页/目录页/chunk I/O 内部尚无新检查，不宣称抢占式取消或端到端固定时延。metadata 和输出仍未统一预算，真实布局、发布、恢复与回收准入尚待完成。

进度：S0 1/4（25%）、S1 1/7（14.3%）、S2–S6 0%、总体 2/34（5.9%）。未运行全量测试或 benchmark，未提交或推送，未更新正式数据库文档。
