# 原生查询资源所有权推进记录

日期：2026-10-15。本轮推进 S5.3/S5.4 的实现，尚不验收这两项或本轮五项优先目标（S5.3、S5.4、S5.5、S6.1、S6.3）。已验收进度仍为 22/34（64.7%）。

## 已接通的所有权链

协调器移入公共 include 目录，原执行目录保留兼容 include。ProcessResourceDomains 持有共享的 512 MiB 进程预算、16 MiB 维护保留空间和最多 64 个弱引用数据库槽位。原生已打开文件身份与持久 DatabaseId 共同选择一个 256 MiB 数据库域；同一物理文件的硬链接别名共用域，不同文件分别计数据库额度。数据库类别上限沿用 A6 的查询/缓存/写入/维护/代码 192/64/128/32/0 MiB。本记录只接入查询消费者；这些类别上限本身不等于其余类别已实际计费。

原生 QueryEngine 创建单一有界查询账户，保留现有物化上限（默认 64 MiB）及更小的驻留内存策略。已连接的读取执行局部预算共享该账户；调用者提供的账户必须属于原生域，且不得提高查询策略。事务 overlay 同样使用引擎原生域。资源注册/准入未嵌入元数据发布门。

MaterializedByteBudget 在发布计数前，同时对 PMR 请求和手动保留执行局部及父级准入。拒绝不改动任何计数，底层分配失败退还两级计费，独立局部预算不能倍增查询/进程额度。共享可用空间观察与实际准入复用同一有锁计算，包含维护保留空间。非嵌入载荷可把保留转交为拥有父级账户的 lease，不先退款再重新申请；嵌入父对象须先重分类。

读取输出列和驻留批次槽位分别计费。成功输出把最终保留转交 QueryResult；失败时先销毁部分输出，再退还执行保留。结果在执行结束、后端关闭及重开后继续持有账户/数据库/进程。深复制先申请第二份计费再复制数据，移动转移所有权，赋值先释放旧容器再释放旧计费；后续行、列和通知增长包含 vector 扩容重叠及嵌套/实体堆估计。计数描述已提供的所有权/容量估计，不能冒充完整 RSS 或所有 allocator 私有元数据的保证。

## 验证和剩余门禁

先后通过 25 个基础测试、116 个读取/输出测试，最终通过 15 个相关 suite 的 146 个测试；仅编译链接受影响模块，未运行全量测试。末轮覆盖真实原生查询、物理只读零写入、硬链接身份、关闭/重开与保留结果、外来账户拒绝、事务回滚，以及 query scratch 和隔离回归。源码和证据身份见 proof.json。旧异常断言忽略 nodiscard 返回值的问题使用显式 void 转换修正，预期异常未改变。

缓存/计划/码本分配、mutation/写私有页/undo 缓冲区、维护/恢复工作区、通用 BoundedBatch 容量审计及有界退役积压尚未全面接入。解析/编译、部分 procedure/mutation 预算及其输出仍在本链路之外。分区哈希连接/聚合、完整资源压力/故障/稳态矩阵仍需完成。不能据此宣称完整进程内存治理或验收 S5.3/S5.4，也不能把部分源码回归当成 S6.1 最终验收。本轮没有跑最终性能测试；独立优化前基线仍显示与 Kuzu 的显著差距。
