# A3 不可变稀疏组更新候选

日期：2026-10-12。

新增 SparsePropertyGroup 实验容器，将字段目录、组身份和只读列载荷共同拥有。freeze 先校验完整目录与列覆盖关系，再复制外部缓冲并再次验证拥有的结果。更新先验证源组及 owner 路由，生成下一身份的字段目录，复制列引用描述符，仅重编码目标列；未修改列以 shared_ptr<const vector<byte>> 复用。空 presence 列从新组移除，旧组继续拥有原列。

回归覆盖遗漏列拒绝、freeze 后外部载荷修改不影响组、新增 NULL、删除最后字段与全空组、新字段插入、未修改列指针复用、类型冲突失败后旧组值不变。五个限定模块共 61 项通过，构建开启 Werror；日志、JSON、源码 hash 在同名 results 目录。

这是内存候选，不是生产原子发布或持久页回收。空列移除仅表示新候选不再引用它，旧快照生命周期靠 shared ownership 表示。完整组校验仍遍历所有列，字段目录仍整份复制；尚无组级预算 allocator、异构类型回退及持久 descriptor/page 身份。后续需接通这些能力及恢复/回收成本验证，不能将候选作为已验收生产布局。

进度保持 S0 25%、S1 14.3%、S2–S6 0%、总体 2/34（5.9%）。未运行全量测试或 benchmark，未提交或推送，未修改正式数据库文档。
