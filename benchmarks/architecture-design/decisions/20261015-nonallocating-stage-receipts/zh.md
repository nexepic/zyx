# 暂存状态更新后回执不得再分配

原生暂存和事务 overlay 在更新暂存状态后返回 const 局部 LogicalGraphMutationBatchResult。编译器不执行命名返回值优化时，const 向量只能复制；此时 OOM 会让已经进入事务前缀的创建操作报告失败。改用非 const 局部变量，使隐式移动不可抛异常，并以静态断言保护回执类型的不可抛移动合同。不修改持久格式。

分别将旧/新 backend 与 overlay 编译单元加上 -fno-elide-constructors，链接到独立故障工作进程。旧原生路径在第 10 个分配点、旧 overlay 在第 21 个分配点复现：报告失败的创建出现在前缀提交后。修复版不依赖复制消除，通过全部 10 个原生和 21 个 overlay 创建分配点。归档包含冻结旧源码、编译参数/hash、日志及复现入口。

常规构建当前源码的 118 项受影响测试通过。当前故障矩阵通过 6/6 原生暂存、17/17 overlay 属性暂存、10/10 原生创建、21/21 overlay 创建，以及提交正常轨迹 3,923 个分配点中的 96 个抽样、4 项既有测试和同文件 32 轮崩溃恢复。恢复后文件大小均为 1,572,864 字节，每轮只读 SHA256 不变。提交抽样明确不是全遍历；旧源码完整提交遍历另存为历史检查点。没有运行全量单元测试或性能测试。

没有新增固定验收：22/34（64.7%）。继续补齐资源归属、有界积压、分区算子及最终验证。后续 ID 租约注册审计发现持久命名空间发布后分配 map 节点及部分注册风险，不在本次回执修复范围内。
