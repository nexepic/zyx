# 内存 Superblock 校验去除重复编码

完整宽属性场景在原 1800 秒超时后，停止评测待修复版本。保留旧版所有完整结果与取消状态，未提升时限、文件或内存额度。

578 次带完整类型/值检查的诊断发现：元数据访问反复调用 `SuperblockCodec::encode` 校验已经在内存中的描述符，完整编码和 CRC 的输出随后被丢弃。新增直接校验入口，29 处调用复用原有 `validateSuperblock` 字段校验器；没有放宽任何字段检查。文件编码、磁盘 CRC 解码和 A/B 发布路径保持原样。

39 个必要模块、567 项测试通过，包含 3 项新测试：验证直接校验不生成 CRC、全部 13 种根引用的非法形态、生命周期/保留区/标识和对齐边界。未跑全量单元测试。

相同的 578 次诊断操作在修复前后均通过精确结果检查。64 字段动态属性更新累计 CRC 调用从 106669 降至 34153，逻辑读写字节相同。诊断启用 instrumentation，修复后同时有测试编译，故不比较其运行时间，不作端到端提速验收。

进度仍为 31/34（91.2%）。完整动态/宽属性的时限、属性写入尾延迟及最终统一窗口仍需验证；本修复不新增验收，也不声明超过 Kuzu。原始轨迹、源码/二进制身份和复现脚本见 proof.json。

修复后 13 家族 smoke 的 886 次完整结果检查也通过，整次运行预算为 120 秒；不替代完整合同或性能评测。
