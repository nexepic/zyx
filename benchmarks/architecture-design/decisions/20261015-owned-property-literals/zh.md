# 不可变字面量载荷的资源归属

组件证据；仍为 22/34（64.7%），不新增阶段验收。

保留的 PropertyValue 字面量采用不可变载荷。真实共享控制块/载荷对象经拥有分配器分配，标准字符串、数组和 map 的嵌套堆在复制前申请审计上界，载荷销毁后才退款。同一资源内复制共享只读数据，替换构造完整候选后交换；活动资源变化时先深复制到新资源，防止 CACHE 持有 QUERY 的私有账户。空值不分配载荷；移动后的空 owner 保留分配权威，可在目的销毁后重用。

观察到的容量只用于缩减预约，不在复制后追加申请。map 源桶数、嵌套深度 64、标准分配器大块前缀和 Debug 代理沿用已审计模型。691 项相关模块测试通过；107 个独立案例通过，含 10 种字面量实际复制/共享/替换形状（大字符串、二进制、嵌套列表/map、稀疏桶表），未观察到超出预约的请求，关闭后存储及额度归零。缓存长路径仍为 96 点抽样，不宣称穷举。

这是字面量载荷组件，动态容器槽位、其他工作区和稳态验收仍待完成。运行证据仅 Linux/clang19/libstdc++14；没有新性能基准、RSS/Kuzu 收益或另两平台运行结论。
