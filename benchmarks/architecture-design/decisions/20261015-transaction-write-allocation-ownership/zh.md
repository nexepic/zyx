# 事务对象及已分配 ID 缓冲区的分配归属

本记录仅为组件实现，已验收仍为 22/34（64.7%）。

原生事务对象及其保留的节点/边 ID 向量共享有限的 WRITE 类账户。对象前缀在多态销毁、构造失败及关闭对象存活时间超过后端时保留分配器。只读事务对象的元数据也使用这一计费类别，不授予任何磁盘写权限。空事务不会预付完整的写配额。

复制候选 ID 向量及按范围准确扩容前先准入分配请求，复制显式保留原分配域。后续语句被拒绝时保留先前暂存的 ID，可释放压力后重试，已放弃的持久 ID 租约不会复用。终态清理先销毁 ID 缓冲区再退还额度；尚未销毁的关闭事务继续为自己的对象本体计费。直接父账户分配器仅用于发布门之外的对象/ID 操作，其他暂存及 COW 仍需预付工作区。

验证：159 项原生事务/属性补丁/重基/写入接口/隔离/资源/临时空间测试，加 1 项关闭对象跨后端销毁的生命周期测试，共 160 项不同测试通过。4 项独立 OOM/终态保留测试通过，关闭对象均保留 1,640 字节的请求分配量，包含分配控制对象和归属前缀。本批排除两项耗时原生排序集成用例，未运行全量测试或性能测试。

剩余包括预留范围与未结租约元数据、变更/属性/撤销/覆盖层/私有页工作区、提交规划、维护和恢复，以及可分区算子溢出和完整故障/长稳验收。本批不等于验收 S5.3/S5.4/S5.5/S6.1/S6.3。
