# A3 回退更新的增量类型判断

日期：2026-10-12。

AdaptivePropertyColumn 在构造时记录五类数量：缺失或 NULL、整数、浮点、布尔、其余类型。替换只解码目标槽位，扣除旧类并增加新类，判断是否满足固定列准入。前后均为 canonical 时不再读取其他槽位的值，仅遍历至多 64 个槽位共享未变化根并重新编码目标根。布局转换仍完整重编码。类型计数由封装内部维护，不接受外部未验证计数。

新增连续更新测试覆盖多个字符串逐个移除、整数与布尔混合、浮点插入、删除最后冲突类型、恢复字符串、NULL 与缺失转换；每一步与直接 canEncode 判断及完整值读取对照。五个限定模块共 73 项测试通过。构建日志、测试日志、JSON 与源码 hash 保存在同名 results 目录。

本轮完成实验对象的局部更新判断，未证明生产访问或页复制成本。五项 size_t 计数为额外内存元数据，尚不纳入载荷字节数；持久化格式、统一预算、取消、权威路由、共享页和迁移回收仍待闭合。

进度保持 S0 25%、S1 14.3%、S2–S6 0%、总体 2/34（5.9%）。未运行全量测试或 benchmark，未提交或推送，未修改正式数据库文档。
