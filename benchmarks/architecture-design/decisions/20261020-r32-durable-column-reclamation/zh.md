### 2026-10-20 R3.2：真实列修改及转换源池回收

证据：`benchmarks/architecture-design/decisions/20261020-r32-durable-column-reclamation/`。

- 前向转换不再为清空的 ROW 页写出空 COW 副本，原子删除其当前 Page Directory 映射。只在每个来源池至多31个物理 frame 的当前路由均由本次转换取代/删除时退休整池；含未转换当前页的池保留。旧 pin 的原始物理字节不动，退休队列与目录/描述符同批发布。
- 元数据拥有既有列标量修改入口，最多64个固定大小 cell、共享账户不超过1 MiB。认证 owner/token/来源代际后合并 COW，仅改实际涉及页，保留其他字段字节及四目录根。支持兼容类型和 NULL；no-op 不发布新代际。新物理帧先写，Page Directory、描述符和可退休旧池随后一次 A/B 发布。
- Native 事务显式暂存 cell 副本并保留账户和 pin；移动、回滚、冲突及早期取消后重试均覆盖。不允许与 Entity、ID 预留、普通 Property、索引或 Vector 混用。隔离入口对存在 SystemCatalog 根的数据库保守拒绝，尚未承担派生索引/约束更新。
- 相关12个模块：默认格式246通过；候选格式368通过、1个条件跳过（该默认格式专用保护在默认构建中已执行）。覆盖旧快照/重开、缺失字段/类型变化/重复 cell 拒绝、quota/写帧后取消退款重试、A/B恢复，以及三轮转换→列修改→逆转换→释放旧池后的物理槽复用。最大64 owner/4096成员双向1 MiB测试仍通过。未执行全量单测或性能基准。

这些是实验格式32的有界真实生命周期实现，不是生产采用或完整 native 写路由。通用字段增删/类型变化和整 owner 删除尚未持久发布；多组增量目录、通用 LargeValue 与引用回收、native 活跃期间的通用回收/搬迁及完整成本/同执行器 ROW 对照仍待完成。**R3.2/R3.3/R5.1/R5.2/R5.3 均未新增验收，总进度仍13/24（54.2%）；按会话要求不提交、不推送。**
