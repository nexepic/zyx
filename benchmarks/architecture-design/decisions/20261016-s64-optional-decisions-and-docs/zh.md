# S6.4：O7/O8 不采用决策与本轮最终文档

本次明确不采用额外 SIMD、算子内并行、压缩方案、LTO/PGO 和 LLVM JIT；不新增依赖、线程或代码缓存。依据 optimization.mdx 第 4 节“O7/O8 没有证据时记录不采用即可”，不构造没有收益依据的原型。逐项理由、再次评估条件见 [decisions.json](decisions.json)。这只完成该固定决策交付，不替代 A1–A6 或剩余性能验收。

实际归因来自 [S0.4](../20261016-s04-hotspot-and-falsification/proof.json)。五类查询保留了真实函数样本，但采样时钟与 OS CPU 时间不一致，不能宣称精确的表达式 CPU 占比。三进程机制比较中，含转换的 typed filter 比 generic 慢约 1.587 倍；这不证明所有 SIMD/JIT 方案无效，只表明现有证据不足以新增生产复杂度。四客户端正确性不是并行扫描收益；不能增加线程后冒称同资源提速。已有 LZ4/Zstd 能力与 `-O3 -DNDEBUG` 保持原样；不存在获准的新增压缩、LTO 或 PGO 结论。

## 最终实现快照与边界

源码采用 [03436b7a 冻结及定向回归](../20261016-cache-decline-delete-budget/proof.json)：130 个受影响模块、2,882 项测试通过；13 类完整结果 smoke 与额外 4,000 次四客户端操作通过。此处复用既有证据，不因文档再次运行测试或性能矩阵。运行验证环境为 Linux；不声称已实测 macOS/Windows。

查询路径保持绑定/类型化批次、通用动态类型回退与拥有输出；Top-K、快照身份和预算只按已有准入路径执行。DELETE 字面量输出使用私有引用消费者，完整公共实体输出保持拥有语义。可选缓存拒绝走有准入的读取后备路径，不等同于损坏。写入保持 COW、data-before-root、A/B 发布和默认 durable sync；冲突不会直接以旧物理页覆盖新版本。

共享 QUERY/CACHE/WRITE/MAINTENANCE 配额与单文件 scratch 沿用 [S5.3](../20261016-s53-budget-and-spill-acceptance/proof.json)；已支持排序与分区 DISTINCT/UNION，未支持的聚合/join spill 显式拒绝。逻辑只读与物理只读边界不改变。维护临时证据在完整校验后释放；完整 10,000 节点删除/大值回收的正确性通过，但不冒称稳态性能通过。

实际文件版本为 envelope **5**、Superblock **31**，与当前源码、真实 smoke FORMAT 和[单文件规范](../../../../docs/apps/docs/content/docs/zh/zyx/architecture/native-single-file-storage-plan.mdx)一致。旧 4/30 文件拒绝策略、开发格式和发布前迁移门槛沿用 [A7](../20261013-a7-format-boundary/zh.md)，不承诺稳定格式或迁移器。此次文档/可选决策不改变文件与 Driver ABI。
