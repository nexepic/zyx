# R3.2: Field-preserving ordinary topology publication

The ordinary declarative mutation executor seals an internal proof tied to the metadata instance, entity store and exact source superblock. Uncoordinated low-level transactions cannot obtain this proof. The writer authenticates the native descriptor and source controls, rejects field-root and schema changes, and refuses owner insertion, deletion or property replacement inside any native group. Inline property changes are included in the sealed owner list even when no ROW root changes.

Allowed operations preserve native fields: ROW owners outside converted groups and native label changes use existing scalar, constraint, count and Vector coordination. The native descriptor relocates inside the same final publication. Current and old snapshot reads must agree on unchanged native fields.

Writable backend adapters attach read-only to native pools; the typed writer remains responsible for mutation. Startup tail truncation retains its complete allocation and snapshot census and changes no logical roots. Recovery of actual orphan scratch and native-group CRUD remain outside this implementation.

The initial insertion refusal test incorrectly assumed ID49 after reopening a48-owner database. Durable leases skip the unused range, so this public operation correctly creates an owner beyond64. The corrected case verifies that behavior and unchanged native liveness; it does not claim coverage for insertion inside a native group.
