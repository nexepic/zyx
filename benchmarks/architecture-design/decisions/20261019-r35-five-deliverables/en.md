# Reproducible R3.2 pre-integration checkpoint

The five fixed deliverables are R3.2, R3.3, R5.1, R5.2 and R5.3. None is complete at this checkpoint. Implementation steps are not stage acceptances; the active denominator and admission contracts remain unchanged.

`FixedBTreeMapMutation` canonicalizes final changes by logical prefix in an existing native shared tree. Repeated SET/REMOVE produces one erase-old/insert-final pair; final no-ops stage nothing and native empty commits remain rejected. PMR charges retained map nodes. Cursor boundary admission is separately forwarded; native cursor/source and transaction staging buffers retain their separate owners. This planner must exclusively own this index's transaction operations. It does not bootstrap a tree, assign final locators or perform global integrity. A staging failure rolls back the entire graph transaction. Native rollback now borrows retained logical-ID ranges instead of allocating copies. Selected tests protect old pins, reopen, refusal/retry and inactive state.

`ReservedGroupConversion` is bounded experimental planning only. It retains an actual account reservation for its fixed holder/workspace (below 1 MiB), with at most 64 actual owners and 4096 memberships. It validates native owner kind, positive IDs through INT64_MAX, group identity, unique owners and strictly increasing tokens. It classifies actual fields rather than expanding a global token universe. At least 48 present cells with uniform non-NULL int/double/bool qualify for a candidate column. All-NULL fields cannot infer a new type; mixed, sparse and other values remain borrowed canonical extension inputs. Missing and NULL remain distinct; floating bits round-trip exactly. Reverse owner projection visits actual fields in token order. Large values are borrowed without copies; callers separately own/charge source memory and must keep immutable input and budget alive through the plan. This does not apply cost admission, persist extensions, manufacture LargeValue references, install graph routing or complete native forward/reverse conversion.
