# 原生变更嵌套负载准入

组件实现与验证；验收进度仍为 22/34（64.7%）。

普通原生暂存现在先为私有规范化输入准入，再复制负载或预留新的创建身份。估算遵循支持的标准容器复制行为，拒绝过深嵌套，在估算及外层分块复制时检查取消。请求槽位继续由 PMR 所有，保留的字符串、列表、字节与 map 使用独立 WRITE 租约；转移不经过退还/重新准入，缓冲区先销毁后退还额度。新语句还会预付原暂存前缀副本，并在接管输入前预留完整外层槽位上界。

属性折叠在 PMR map 中借用键和值，构造结果前预付完整结果副本工作区。已消费输入在退还工作区前释放。保留这些输入的反证构建暴露了 190,971 字节未覆盖分配请求；修复后的独立分配观测在五次原生暂存中均得到零未覆盖字节，包括小属性扩张及连续 patch 合并。私有保留请求峰值为观测到的 357,601 字节。这不是 malloc 元数据或 RSS；观测从原生首个检查点开始，排除调用方按值输入。

规范化批次提前准入嵌套副本、标准外层向量、持久回执和创建计划向量。去重表借用保留请求，直到最后的已预留复制。规范化 patch 槽位使用 WRITE 分配器；增量负载与临时替换槽位在复制前准入。undo/overlay 嵌套负载、快照源物化及其他发布/编译工作区仍需补齐，尚非完整堆计费。

最终 63 项相关模块测试通过。此前较大选择运行了 1,982 项，其中 1,979 项通过；定位到私有副本拒绝提前及不再消耗 ID 后，修正了三个旧断言。最终模块选择覆盖这些断言和消费输入生命周期修复，不声称最终源码已重跑全部较大选择。

冻结的最终 worker 通过 583 个独立案例：576 个分配失败点（短路径穷举，长路径各采样 96 点）、四个终态案例、两个堆计费案例（22 种标准/输入形状及五次原生暂存）、一个包含 32 次真实崩溃/只读检查/恢复的流程。关闭原生事务在销毁前保留 1,856 字节请求，低于未放宽的 16 KiB 上界。各阶段采样数见 proof.json，原始日志与源码见 module-evidence.tar.gz。
