# Transaction state destruction

Component checkpoint, no new acceptance: 22/34 (64.7%). Ordinary mutation slots, patches, preview capabilities, issued IDs and ordinary/streamed lease ranges now live in one optional RetainedMutationState. Terminal paths destroy that state directly. They no longer construct replacement empty vectors/batches or assign empty streamed lease vectors while cleaning up. Active streamed-append failure clears its consumed ledgers without allocating, retaining capacity until termination. Only the preview member remains mutable in const methods. An independent strong allocation owner remains available after closure for overlays and deallocation.

Read-only and streamed commits construct their empty public receipts before changing transaction state. The successful return moves that prepared receipt, so a standard-library allocation in an empty result constructor cannot fail after the state has been closed. Ordinary commits keep their existing non-const movable receipt. Read-only, ordinary and streamed terminal branches all release retained state.

All 1,652 enabled selected tests in 66 suites pass. One existing disabled scale fixture was not enabled or changed. The 177 focused transaction/overlay/streamed tests pass. The frozen worker passes four terminal cases, including rollback with every new heap allocation denied and 40 separately staged reservations, plus requested-allocation retention checks (1,832 bytes of closed allocation footprint on this build). Its allocation matrix tests 96 evenly spaced points each for commit (normal 3,941), direct/fresh capabilities (163/169) and scratch write (1,698); short stages (5/16/10/21/4/17) are exhaustive. The sampled matrix and one 32-cycle real crash flow total 462 passing cases; this is not relabelled as an exhaustive matrix. Every recovered file is 1,572,864 bytes and read-only inspection preserves its SHA-256. No full suite or performance campaign ran.

Linux x86_64 execution is verified. Windows/macOS execution is not claimed. MSVC source at da52dc0fcadbd83690cfd1ed32408d2847439493 confirms that iterator-debug empty container construction can allocate proxy nodes, including calls from noexcept constructors; xhash also constructs a list sentinel and two bucket iterators per bucket. Source files and their license are archived as audit evidence. This change removes empty-container construction from terminal state release; it does not establish safe admission for every MSVC debug container constructor or full heap governance. Those remain separate work.

Nested Property/string/map buffers, COW/commit/overlay workspaces, compilation/IR ownership, all maintenance budgets/backlog, partitioned operators and whole-stage acceptance remain open. The earlier full matrices belong to their own source checkpoints.
