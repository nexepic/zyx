仅为组件检查点，没有新增验收：22/34（64.7%）。普通变更槽位、patch、preview 能力、已发 ID 及普通/流式租约范围集中到可选 RetainedMutationState。终态直接销毁，不再构造替代空向量/批次，也不在清理时赋值空的流式范围向量。活动流式 append 失败时无分配清空台账，容量保留到终态。const 方法仅允许修改 preview 成员；独立强分配器所有者在关闭后仍可供 overlay 及释放使用。
