# 查询私有读工作区及可选缓存的最终预算复验

完整倾斜聚合的精确失败栈定位到标签 token/目录解析仍借用 CACHE。查询执行及私有快照现在显式继承 QUERY；读会话的私有查找/FIFO 管理结构使用 QUERY，独立缓存负载保留 CACHE 预约。双分配器标签替换的反证捕获了错误交换，修复后全部余额归零。

范围游标按已认证根节点实际高度预留路由，且只保留需要的子引用前缀；不改变认证、遍历顺序或持久化格式。已解码结果后的额外页面缓存副本在额度不足时明确放弃，只捕获两种额度拒绝，其他错误继续抛出。原有 32 KiB 成功测试保持原额度；新增 CACHE 完全占满时的节点聚合及缺失关系类型计数通过。

111 个指定模块、153 个套件、2,332 项测试通过，补充两项完整 CACHE/32 KiB 检查通过；最终 Release 的 13 类/886 次精确结果 smoke 与 23 项 Python 基准合同测试通过。没有运行全量单测或接受性能样本。完整合同继续；10 万组完整输出的 QUERY 拒绝明确为 N/A，全部键/计数另通过有界分段验证，不将拒绝视为性能成功。此记录不新增进度，源码冻结另行更新 S6.1。
