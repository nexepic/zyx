# A2 属性补丁与伴随修改的原子接入

日期：2026-10-12。本轮完成按键补丁与现有 mutation batch 的组合入口，以及直接 SET/REMOVE 链的条件接入。属于 S1.2/S3.1 局部实现，尚未完成整个交付项。

组合入口先验证所有补丁，拒绝同一实体同时完整替换和按键修改，归一化成功后与伴随标签修改一起交给既有原子发布入口。新增测试验证标签与属性一起生效，以及重叠请求失败时属性和标签均不发布。补丁仍按旧布局读取完整属性、构建完整替换，不宣称局部物理写入或性能提升。

直接 SET/REMOVE 链在 snapshot 支持 shaped admission 时，从最终暂存集合与原集合计算 set/remove；修改后恢复原值时可省略属性发布。保留有序语句求值、先构建结果再发布，以及冲突后重新读取和应用整个链。缺少 shaped admission 的消费者保留完整替换路径。补丁源读取有累计字节检查和取消检查，真实容器容量、输入新值所有权预算以及创建/合并路径尚未闭环。

本轮严格编译修正两个已有测试警告：共享 fixture 的可选辅助函数标记 maybe_unused，显式丢弃测试节点创建返回值。没有改变测试语义断言。

验证：定向属性补丁和 mutation runtime 共 173 项通过；显式选定的 22 个测试源文件共 678 项、32 套件通过。该目标不包含全库测试。当前 mutation fixture 尚未启用 shaped admission，因此这些既有 Cypher 测试主要覆盖兼容替换路径；新补丁分支还需要专门 fixture 与端到端测试，不能据此宣布完整接入验收。组合入口的新增 2 项测试已覆盖真实 overlay 路径。

证据在 benchmarks/architecture-design/results/20261012-a2-patch-companion/，包含源码 SHA-256、选定模块配置、构建日志及测试 JSON/日志。验证平台仅为 macOS，不声称完成 Linux/Windows 验证。未运行 benchmark 或全量单元测试，未提交/推送，未更新正式数据库文档或英文记录。构建缓存保留供下一轮复用。
