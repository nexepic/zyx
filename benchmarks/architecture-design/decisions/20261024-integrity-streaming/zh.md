# 完整性扫描与稳定源检查点

已验收总进度仍为 15%，没有性能测试、全量单元测试、提交或推送。

完整性扫描器不再保留所有原始页面、页面身份表、逐实体/属性路由集合或全量 Edge/邻接预期键集合。物理槽先反查精确逻辑目录，再逐目录认证活动目标并比较计数。邻接树保持页面顺序、分隔范围、层级、循环和双向键完整性检查，通过流式键与权威 Edge 交叉验证。叶链只保存前驱。普通页面按同一 pin 重读；原生字段/成员页继续使用专用反向校验。原始大值读取缓冲显式准入，固定页面 codec 副本预留 32 KiB。取消检查释放所有临时账户和 pin。

私有实例在字段规范化前完整校验身份保持的 ROW 克隆，防止退休旧页掩盖孤儿记录。调用方可显式提供最多 7 MiB 校验账户，与原 1 MiB 构建账户合计不超过 8 MiB；默认共享原账户。静态底层构建原语不提供完成发布能力。源原生文件身份、A/B 原始字节和文件长度在阶段边界检查，源变化则关闭并删除本次创建的私有目标；不删除替换到目标路径的其他文件。失败后诊断接口拒绝访问已丢弃镜像。路径转换和清理工作区也在打开文件前准入。

验证：默认完整性模块 71 项，隔离构建链 49 项，默认构建拒绝路径 17 项通过。新例覆盖 128 个大内联状态页和 4096 条边的 256 KiB 账户、取消前/中途退款、孤儿 ROW 前置拒绝、源长度变化、复制中变化和 POSIX 路径替换。Windows 只读句柄未共享删除权限，因此路径替换夹具仅在 POSIX 运行；生产身份检查有双平台实现，尚无本轮 Windows 实测。

保留了三类初始失败：状态页夹具物理槽不足（扩大夹具范围），按需读取误走普通字段页读取器（修正生产 owner 分派），及损坏源夹具在成员发布后调用了受保护写入接口（把损坏移动到复制前，保留生产保护）。

只读结构 census 发现 medium 45350 个当前页面、2363 条 catalog，源写入计数为零。另一个大库完整性诊断链接于后续修正前，已主动中止；它没有完成报告，不是当前实现的大库验收证据。二进制身份与原因见 status 文件，不据此宣称通过资源或正确性门槛。
