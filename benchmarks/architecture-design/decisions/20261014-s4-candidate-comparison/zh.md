# S4.1 验收

一致性协议保留权威 Edge 主记录，遇到覆盖项时先核对身份、端点和类型，再输出或过滤。原生实验实现两种载体：独立 u64 Packed B+Tree 叶值路由到共享认证拓扑值；共享分段值把低度节点合并，并将超级节点划分为每块最多 64 条的有界块。1,100 条记录验证平行边、自环、有界序号续读、旧值快照和重开；有效编码的错误字段或缺失主记录无法通过比较。另一个原生测试认证实际 u64 叶页并解析定位值。

35,200 字节共享载荷的均匀布局为 2 个 chunk，分段布局为 18 个；不同尾部标记避免内容去重复用同一布局。这是物理布局观察，不是端到端 IO、延迟或稳态空间验收。主记录映射仅是测试预期值，不是生产权威来源。

两个候选均未获准生产接入：缺少权威图原子路由、双向变更和基于可达性的退休集成。COW/重开仅证明载体生命周期，不证明图生命周期。持久化常量和保留 EMPTY 树含义不变。S4.1 接受的是已实现的候选对照及保留当前布局的决定；启用新布局仍需补齐门槛并重新准入。没有宣称性能阈值达标。
