# A3 不可变验证候选与实体读取

日期：2026-10-12。

新增 VerifiedImage，通过 freeze 拥有候选镜像副本，先完成全组关系验证，再建立 owner 到原根或 token 到页的索引。对象无公开载荷修改接口，保留自己的槽位表和目录身份。后续读取原根直接定位目标 owner；列模式只按该 owner 实际字段定位并解码对应列，不再解码所有字段列。

扩展布局测试验证两种表示首/末 owner、错误快照拒绝，以及调用方清空原镜像后验证对象仍正确读取。五个限定模块共 96 项通过，本轮扩展已有测试。证据在同名 results 目录。

验证构建仍解码全组，原根模式建索引会额外解码一次；列模式每个选中字段仍校验父页和解码该列至多 64 槽位，尚未直接按 rank 读取一个值。输入镜像副本、验证输出与索引预算未统一计费；不是已接入生产的快照缓存。真实身份路由、发布与回收仍待完成。

进度保持 S0 25%、S1 14.3%、S2–S6 0%、总体 2/34（5.9%）。未运行全量测试或 benchmark，未提交或推送，未修改正式数据库文档。
