# A3 无变化更新复用载荷

日期：2026-10-12。

AdaptivePropertyColumn 的 replace 先检查目标槽位是否具有相同的 canonical 值字节。类型、嵌套结构和浮点位模式均保留；不能把 -0 与 +0 当作无需写入的相同值。缺失和 NULL 区别明确。无变化时复制封装并共享 canonical 根，仍验证正数和结果字节上限。固定列载荷仍是 vector，返回对象复制该有界载荷。

新增测试验证普通值、缺失和 NULL 的重复更新共享所有根、收紧预算仍拒绝、零预算拒绝、-0 到 +0 确实生成新根且旧值保留。五个限定模块共 74 项测试通过，证据在同名 results 目录。

该方法避免重复编码属性根，但相等判断仍为目标值生成两个 canonical 缓冲区，尚无统一瞬时内存预算或取消；不宣称零分配。仍为实验载体，生产路由、页级 COW、迁移及回收待完成。

进度保持 S0 25%、S1 14.3%、S2–S6 0%、总体 2/34（5.9%）。未运行全量测试或 benchmark，未提交或推送，未修改正式数据库文档。
