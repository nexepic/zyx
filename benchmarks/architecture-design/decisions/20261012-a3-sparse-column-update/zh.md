# A3 稀疏定长列不可变单行更新

日期：2026-10-12。

实验列 codec 新增 replace：先验证完整旧编码，再重建至多 64 行的当前列，覆盖单行后按相同 codec 返回新编码。optional 缺失删除字段，存在 NULL 保留 presence。全无有效值规范为 NULL_ONLY；从该状态增加 bool/int/double 允许选择新同质类型，仍存在其他不同类型有效值则明确拒绝。旧字节不改变，不修改其他列。

重建读取复用私有 readValidated，仅一次完整校验，避免每行重复 CRC；私有入口不得接受未经完整认证的数据。新编码仍最多 560 字节，但重新构造整列及至多 64 个临时 scalar；不是原位单值写入，不证明真实页面 COW 的局部成本。混合/变长 fallback 与组级目录更新尚未接入。

新增两项测试覆盖有效值插入后的 rank、删除、NULL、去除末个有效值、改变类型、旧版本读取、混合类型/越界拒绝及损坏旧编码。严格构建与 5 项列 codec、7 项目录、1 项真实快照及 2 项旧编码测试共 15 项通过。证据位于 results/20261012-a3-sparse-column-update，含日志、JSON 与源码 hash。
