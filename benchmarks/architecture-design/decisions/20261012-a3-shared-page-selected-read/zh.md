# A3 共享页选择读取与显式类型切换

日期：2026-10-12。

新增 readColumn，验证容器与目录后按 token 二分定位，只解码选中的子块。不存在字段返回空 optional，存在列返回每槽位 optional 值，列缺失与存在 NULL 保持区分。按明确 kind 调用 compact 或 Adaptive codec，取消检查传播。Adaptive 新增拥有值的 readAll，固定布局使用一次验证批量路径。

replace 增加明确 replacementKind，默认完整自适应镜像，调用方可指定紧凑固定子块。新增同页两类型选择读取、字段缺失、紧凑到异构再恢复、错误 tag 拒绝和旧页保留测试。五个限定模块共 89 项通过，同名 results 目录保存日志、JSON 和源码 hash。

选择读取仍会校验整页 CRC 和完整目录，但不解码其他子块；这是实验逻辑读取，不证明物理 I/O 减少。跨布局替换仍重建目标页，生产身份、统一预算、COW 发布与回收未完成。

进度保持 S0 25%、S1 14.3%、S2–S6 0%、总体 2/34（5.9%）。未运行全量测试或 benchmark，未提交或推送，未修改正式数据库文档。
