## Changes

* TSan retains its complete existing gate, filters and sanitizer settings. The job limit is 60 minutes and the shared evidence deadline is 55 minutes, preserving five minutes for upload. Previously the deadline expired at 10:31:48 while compilation was at 780/876; dependency installation had consumed about 10.5 minutes and tests never started. Increasing only the build command timeout would not change the shared deadline. The new maximum job allowance is 20 minutes higher; actual future duration is unverified.
* Codebook fault injection measures cold-read allocation count independently of construction, injects relative to the constructed resource state, asserts the injection was hit, checks rollback to the live constructor baseline, retries and checks final destruction refunds. A prior allocation also exercises a nonzero resource epoch on Linux. No constructor allocation or live map/list header is treated as free.
* Empty Property patch validation returns zero before constructing its unused target set. With no patches there can be no overlap with replacements or deletions. The caller's cancellation checkpoint remains before this method. This avoids MSVC's allocating empty tree header before the actual private-input preflight; the CI's 16-byte parent rejection is consistent with this path, although no native allocation stack was available. Nonempty patch validation is unchanged.
* WRITE fixture expectations include the two nested standard vectors in an empty Node creation request. Their objects are already in `sizeof(request)`, but MSVC debug proxy storage is not. The production fee, limits, rollback and denial assertions are unchanged.
* Known-cardinality procedure results reserve final vector backing before publishing output rows, including entity outputs. The reserve checks all currently retained source/output storage plus the actual new backing request. Later output creation/publication and source/result overlaps retain their checks; quota-denied speculative reserve falls back to incremental publication. This avoids growth copies of previously published MSVC maps without changing public types, ABI or reducing relocation charges where growth still occurs. The old scalar-only preflight declined entity outputs; CI recorded simultaneous source/result/relocation fees at that growth site. Native Windows success is not yet established.
* The evidence wrapper prints bounded failed-test identities and assertion source locations from retained XML after its console tail. It does not print assertion payloads, modify child exit status or increase existing log limits. A 256-case limit and per-field truncation are explicit; current 59-case failures fit. Tests cover console truncation, payload exclusion, bounded reporting and unchanged exit behavior.
* Optional sort RSS samples identify first spill, input completion/merge, output and completion. They retain the existing process cap of 24 reports and do not call the allocating ASan statistics printer at these phase boundaries. Actual RSS guard, 64 MiB limit, 8 MiB materialization bound and sanitizer settings are unchanged. Both hook-disabled and sanitizer-enabled syntax were checked on Linux.
* The standalone string probe now also independently intercepts ordinary `operator new/delete` for small map layouts of value widths 88/104/352 and alignment 8. It reports retained requests, simultaneous request peak, model bounds, count, buckets and overflow, and checks final refunds. Fixed bookkeeping avoids measured sampling allocations. This is not a measurement of arbitrary values/over-aligned allocation APIs. Linux measurements remain below existing upper bounds; no production upper bound has been reduced on the strength of a different platform's sample.
