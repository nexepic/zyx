# Revision codec work in progress

This branch is an isolated implementation workspace based on `5d75600c`; it is not ready to merge or push. The Superblock now has independent nonzero graph/schema revision fields in checksummed payload bytes. The temporary version constants distinguish this experimental layout from this baseline's existing variants; they are not the lost final format version, and the final latest-format-only policy still requires unifying/removing old selectors and migration paths. No graph/schema publication, owner revision, snapshot binding, ABA protection or recovery integration is implemented by this checkpoint. Do not rely on the constant initial revisions for conflict checking.
