# Procedure retained-result budget conflict

The frozen 77aa5367 production binary passes the historical MetadataJointRetentionRejectsLowBudgetAndCanRetry at 7500 bytes. Independent measurement of its returned owning result on Linux/libstdc++ gives a conservative **8326-byte lower bound**, repeated twice. This sum uses the actual row-vector capacity times sizeof(Row), column-vector capacity times sizeof(string), the number of hash entries times sizeof(Row::value_type), each PropertyValue-list capacity times sizeof(PropertyValue), and the capacity plus terminator of strings longer than sizeof(string). It deliberately excludes bucket arrays, hash links, allocator metadata, stack state, source rows, and sampling machinery. PropertyValue is 64 bytes and the row key/value pair is 360 bytes on this target. Thus an actual-allocation ceiling of 7500 cannot hold this current public owning result representation. This is not an Apple/Windows measurement or a universal ABI size claim.

An independent fixed-table global-new probe records live requests. Its first execution also includes lazily initialized scalar function registration: those global allocations must not be attributed to the query. The second retained set contains PropertyValue arrays (3840), string requests (3150), result hash nodes (1128), plus row backing/buckets/columns and fixture logs. These observations corroborate the lower bound but do not define which allocations the old logical estimator intended to charge. The probe does not intercept C malloc or preexisting allocations.

An isolated production-TU experiment removes the duplicate embedded ResultValue sizeof from output estimation and accounts retained source vector capacity and per-row heap only during publication. It passes 80/82 related tests; the 4096 converted-query-vector refusal becomes a success, and the historical 7500 metadata success now refuses. Neither this candidate nor its numeric assertions are accepted as a fix. No threshold was changed. The tiny-vector case needs separate lifetime accounting; the metadata case requires reconciling the old logical-estimate success contract with an actual retained-memory contract (or changing the result representation), rather than pretending its current heap fits.

Evidence includes measurement output, fixed-table instrumentation, and the local build driver. Paths in that driver refer to this session's generated link command; it is provenance, not a portable build system. Only focused tests were run in those measurement executables; the unmodified 77aa full-suite evidence is separate.
