## Root causes and changes

* BTree restart binary-search probes only need validated borrowed key bytes. Previously each probe constructed an owned key (and a debug STL proxy). The new regression demonstrates four allocations with the old production TU and one with the new TU, checks independent returned ownership, and confirms refunds. CRC/page validation and returned-entry ownership remain intact.
* Procedure map reservation was re-reserving a table already large enough, issuing another bucket grant and shrinking 37 buckets to two in the red test. The new path reuses an admitted table only at unit load factor and sufficient capacity; embedded singleton buckets and custom load factors keep the conservative path. Growth, insufficient-budget rollback and retry remain tested.
* Remaining MSVC hash-node formulas are unified with the audited `standardHashNodeBytes` layout helper. Buckets, iterator proxies, sentinel nodes and large-allocation prefixes remain charged. Compile-time MSVC checks cover actual string and PropertyValue map nodes. This is not native Windows execution evidence.
* Four streamed tests created a second independent writer, contrary to the single-writable-owner contract and Windows byte-zero lock. Competing publication now uses the same backend; original staging/rebase/corruption/retry/reopen/integrity and old-snapshot checks remain. The public writer contract is unchanged.
* Token cardinality fixtures used fstream-only IO, which cannot take the existing native Windows lease-aware read bridge. They now own native handles with IO/catalog destruction preceding handle close. All 13 fixture tests passed locally. This is a fixture read path correction, not broader multi-writer support.
* The macOS buffered-sort test assumed 256 KiB must fail. It now tests rejection below an independent retained-object lower bound and success at a fixed 512 KiB efficiency ceiling, with all 300 values, exactly 256+44 batched reads, no point/whole reads, resource charges and final refunds. The success ceiling is fixed, not inferred from the current measured peak. Local query budget peak was 302448 bytes, escaped result account 251464, independent retained-object lower bound 232800.
* Chunk workspace assertions include real vector heap/proxy bytes. The schema policy test uses a fixed 8193-row fixture whose independent retained lower bound exceeds its unchanged 1 MiB restrictive policy; this isolates durable policy from an unrelated 64 MiB result ceiling while preserving all rows and endpoint checks. No production limit was raised.
* Bounded scalar evidence survives console truncation. Windows isolated coverage now includes all observed failure identities and new regressions; macOS includes the buffered-sort failure. Values are numeric/boolean only, bounded per case, with explicit truncation. Original gates remain required.
