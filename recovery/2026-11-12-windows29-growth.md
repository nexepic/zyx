## Substantive changes

Result row growth retains the existing public row type. Instead of relying on `vector::reserve` to choose a deep copy when map movement may throw, it allocates a destination array, constructs all empty destination maps, and only then swaps each map's payload and the array. All potentially allocating work completes before the first source mutation. A failure constructing any empty destination leaves source contents, payload addresses and capacity unchanged. Empty source vectors keep the ordinary reserve path and do not create an extra temporary vector proxy.

Admission retains both arrays, all destination empty maps, and the temporary vector proxy. Their fees are real and remain included; copied row payload fees disappear only because those payloads are no longer copied. Empty maps remain funded until destruction. Charged result growth and both charged/uncharged ordinary `addRow`/`reserveRows` paths use this policy. Keys, values and their addresses survive relocation; API row type and owner layouts remain unchanged.

Final read-result growth still prefers doubling when affordable. When spare capacity does not fit, it admits the exact necessary capacity using the same complete peak formula. Local `wouldExceed` only checks local headroom, so typed local/parent quota failures also retry the exact capacity. Non-quota exceptions are propagated unchanged. A failed exact attempt still fails the query; no threshold or proxy fee is relaxed.

Tests include a row with a throwing move and forbidden copy: ordinary vector reserve tries the forbidden copy; the swap path does neither. Injected failure in the second empty destination proves rollback and retry. Actual QueryResult map values retain their addresses through charged and uncharged growth, with complete final refunds. End-to-end 33-row tests exercise a tight local bound and a wider local bound under tighter parent account pressure; they validate every value and account refunds. Existing budget tests keep their original limits. Diagnostic fixed numeric metrics publish successful bound/capacity without arbitrary payloads.
