- Windows injected-allocation termination: the ordinal, request size/alignment and completion of catch and retry narrow the failing stage; a terminate handler attempts symbolized frames with raw addresses and executable base as fallback. Symbolization depends on the hosted Windows runner.
- Windows vector and retained-property cases: separate processes preserve bounded diagnostics for each previously failing case. Local materialization, prepaid-resource and parent account rejection/refund records include sizes, current usage, peak and limits; column read records include batch sizes and actual retained estimates. These do not measure allocator metadata or RSS.
- macOS wide-selection, coordinated prefetch and tight exact-once case: the traces report the read batch, charged structures and payload, and the source line and live usage at each pressure split. They distinguish a read-before-split from admission refusal, without printing property values.
- macOS eight-group and shared-large conversion: string request-bound traces and the independent fresh-string allocator sample distinguish a conservative estimate from observed requests. The sample covers only a finite range and the runner's actual standard library.
- macOS CSV: the existing test prints the actual exception on mismatch; the parser trace adds requested vector growth, old/new capacity, retained bytes, peak and bound, allowing the earlier parse rejection to be distinguished from map conversion.
- ASan/UBSan: the former stack-overflow case runs first with slow fatal unwinding, then the original full gate runs independently. The timeout increase may still be insufficient on unusually slow runners.
