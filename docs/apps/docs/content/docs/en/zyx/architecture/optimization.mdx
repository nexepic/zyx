## 1. Scope and invariants

Implement only three connected paths: **incremental metadata commit, directly typed scans, and bulk import reusing those mechanisms**. Memory views support the first two; they are not a separate general caching project.

- Preserve the general property graph, dynamic properties, multiple labels, stable logical IDs, and existing Cypher, transaction, QueryBuilder, GDS, Vector, Driver ABI, and binding semantics. Vector dimension expansion is out of scope.
- Retain strict single-file storage, COW, A/B Superblock, data-before-root, and durable acknowledgement. Do not obtain speedups by disabling synchronization, weakening validation, adding threads, or using unlimited caches. WAL, group commit, LSM, JIT, and wholesale backend replacement are out of scope.
- Preserve snapshots, read-your-writes, old pins, relocation, safe reclamation, cancellation, and unified resource accounting. Retain existing sort and DISTINCT/UNION spill; operators without spill must fail within explicit bounds.
- Never overwrite published physical pages. Keep logical IDs, physical locations, generations, and snapshot identities distinct. Specify any format change in the [storage specification](native-single-file-storage-plan) first, including versioning and old-file rejection/migration; never overwrite user files.
- Preserve macOS/Linux/Windows portability and the WASM path; list actually tested platforms. Independent platform release gates belong to [release follow-ups](native-remaining-work-roadmap); Linux results do not establish three-platform acceptance.
- Run only necessary affected-module unit tests, not the full suite. `--file` is not a test filter: use named suite/test filters. Documentation-only changes require documentation checks only.

- Queries must return equivalent values, multiplicities, NULLs, and row counts. Writes must have equivalent operations and transaction boundaries and include durable acknowledgement. Report operation, commit, and end-to-end boundaries rather than selecting the shortest measurement.

### 4.2 Attribute costs before changing structure

Use bounded profiling on one representative path per class: ordinary country filter/real grouping, single-property SET, and bulk import. Separate user CPU, kernel CPU, and waiting; measure route visits/construction, decoding, allocation/copying, computation, page writes, and synchronization. Use sampling or exclusive phase timing; never add nested timers. Explain tracing overhead against an untraced control and exclude diagnostic latency from formal scores.

Record `M` (total routes), `k` (changed routes), tree height, unique and repeated page accesses, actual COW pages, metadata bytes, synchronization counts, and peak memory. Reads also record candidates, actual entities/fields, batches, and intermediate objects. Check fixed `k` at small, medium, and large metadata sizes, including height changes and split boundaries; this is a mechanism check, not another full benchmark matrix.

## 5. Accepted incremental-commit contract

P1/P2 are complete. Preserve sorted/deduplicated final changes, changed-path radix COW and one copy per shared ancestor. Capacity and publication share the modification plan. Ownership checks touched pools; intrusive free-pool capacity skips full pools. Retired frames wait for the oldest pin. Post-publication handoff allocates no memory; missing coverage or a mismatched source rebuilds complete reachability.

Keep the approved local-access validation plus complete-integrity contract. Accessed pages/new paths are validated; fresh unvisited corruption is discovered on access/full integrity. Preserve snapshots, atomic A/B publication, data-before-root, recovery and refunds. Initialization, explicit migration and full checks may traverse globally; ordinary commits must not reintroduce full collections or periodic whole-graph reclamation.

Evidence: `20261022-core-cost-routes/` and `20261022-core-cost-ownership/`. One fixed change across 3/300/900 Catalog leaves visits 2/4/5 source route frames, six ownership visits each, and zero ordinary full traversals. End-to-end gains remain P7. B+Tree replacement is not a current task or automatic scope expansion.

## 6. Accepted immutable-view and candidate contract

P3/P4 are complete. Hot bootstrap/radix/Catalog/Allocator reads borrow immutable pages within existing 128-entry/1 MiB cache, budgets, snapshot and I/O epoch limits. Writers use private COW; escaping results copy/transfer ownership as needed. The 99.34% reduction in fixed-page copy counters is not a latency result.

Labels reuse existing B+Trees, atomic token cardinalities and Entity Map. Record/key widths and at most 64 actual candidate locations choose the path. All-node labels scan sequentially; candidates authenticate primary/all labels. Optional cost sampling may fall back only before visitor emission. Multi-label batches fit existing entity-cache bounds to avoid repeat decode.

Evidence: `20261022-core-cost-views/` and `20261022-core-cost-labels/`. Medium filter/group reduce 225000 scanned nodes to 100000 authenticated candidates; 100000 fields remain and now enter typed columns under P5. Old pins, overlay, deletion, rollback, reopen and affected modules were checked. Final lifecycle/performance gates remain P7.

## 7. Accepted direct typed batch contract

P5 connects production ROW selection → direct typed columns → filter/project → actual single/multiple-key grouping → owning output. Numeric bits and synchronous text views enter admitted typed storage; complex values/LargeValues/legacy adapters retain explicit owning fallbacks. Primary workloads do not construct complete PropertyValue matrices or row property maps. Authenticate immutable native identity at batch boundaries while preserving dynamic overlay and batch owner/incarnation checks.

Short-text kernels preflight types/lengths before consumption. Preserve missing/NULL, empty/embedded-NUL text, mixed-type fallback, complete tuples, numeric types/overflow, NaN and DISTINCT. Partial COUNT merges logical values, never cross-batch dictionary IDs. Charge temporary tables and permit admission fallback only before aggregate effects. Four short strings bound cancellation work to 256 text bytes; do not extend this contract to unbounded strings. Results own their data.

Evidence `20261022-core-cost-direct/`: 263 necessary module tests pass. One unchanged traversal-optimizer assertion also fails against the frozen baseline and is recorded separately. Medium filter/group each emit 100000 typed text cells with zero owning fallback in 196 batches. Filter count updates decrease 12500→196; group updates decrease 100000→1568 with unchanged oracles. There are still 100000 selected ROW roots.

The historical same-executor ROW/compact-field synthetic prototype isolates memory representation, excluding actual directories, IO, space and lifecycle. Retain its samples as diagnostic evidence, not authority for persistent adoption, extra progress or Kuzu success. Section 9 records the actual adoption boundary for this round's experimental format.

## 8. Accepted bounded import contract

P6 reuses existing public batches, ID ranges, page-grouped entity/property writes, ordered index changes and incremental commit, without a separate backend or higher limits. Empty insertion targets retain a record-kind completeness proof bound to the exact physical COW root including generation. Local publication maintains it; foreign entity-root changes invalidate it. No cached target is different from never having checked.

Handles for one opened-file identity plus database ID share publication barriers/pin registration while guards retain local registry ownership. A foreign publication discards stale control caches and rebuilds missing allocator/retirement proof and metadata ID bounds against all pins. Every own publication advances local source identity, preserving incremental single-handle writes. Open/recovery must protect other handles' old roots. Preserve accounts, cancellation, constraints, indexes, fault refunds and data-before-root.

Evidence `20261022-core-cost-import/`: 262 module tests pass. Three aligned 65-row batches yield three cache hits and zero entity-directory/global metadata traversals. Public 1000-node/1000-edge ingestion uses two ID ranges and verifies indexes, grouping and topology after reopen. Foreign deletion, 20 alternating publications, eviction of old record caches, old-pin reads, drain and integrity pass. Input/batch/durability boundaries remain frozen under P0; import throughput has no final acceptance yet.
