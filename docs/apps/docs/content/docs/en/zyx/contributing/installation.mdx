# Installation

## Prerequisites

Before building ZYX, ensure you have the following dependencies installed:

### Required Tools

- **C++ Compiler**: C++20 compatible compiler
  - GCC 11+ or Clang 13+ (Linux)
  - Xcode 14+ (macOS)
  - MSVC 2022+ (Windows)
- **CMake**: Build system (version 3.21+)
- **Conan**: Package manager (version 2.0+)
- **Ninja**: Build backend

### Install on macOS

```bash
brew install cmake conan ninja
```

### Install on Linux (Ubuntu/Debian)

```bash
sudo apt-get update
sudo apt-get install -y python3-pip g++ cmake ninja-build
pip3 install conan
```

### Install on Windows

```powershell
# Using Chocolatey
choco install cmake conan ninja

# Or using pip for Conan
pip install conan
```

## Build from Source

### Quick Build

The easiest way to build and test ZYX:

```bash
# Clone the repository
git clone https://github.com/nexepic/zyx.git
cd zyx

# Install dependencies, build, and run tests
./scripts/run_tests.sh
```

This script will:
1. Install all Conan dependencies
2. Configure the build with CMake
3. Compile the project
4. Run all tests with coverage

### Quick Build (Skip Dependency Installation)

If you've already built before and dependencies are installed:

```bash
./scripts/run_tests.sh --quick
```

### Manual Build Steps

For more control over the build process:

```bash
# Install Conan dependencies
conan install . --output-folder=buildDir --build=missing --build="antlr4-cppruntime/*" -s build_type=Debug -s compiler.cppstd=20

# Configure CMake build
cmake -S . -B buildDir -DCMAKE_TOOLCHAIN_FILE=buildDir/conan_toolchain.cmake -DCMAKE_BUILD_TYPE=Debug

# Compile
cmake --build buildDir
```

## Build Release Version

For production builds:

```bash
./scripts/build_release.sh
```

This creates an optimized release build in `buildDir/release/`.

## Verify Installation

After building, verify the CLI tool is available:

```bash
./buildDir/zyx --help
```

You should see usage information for the ZYX CLI.

## Installation Location

The build outputs are located in:

- **CLI Tool**: `buildDir/zyx`
- **Library**: `buildDir/libzyx.*` (public library) and `buildDir/libzyx_core.a` (internal static library)
- **Tests**: `buildDir/zyx_test_suite`

## Optional: Install System-Wide

To install ZYX system-wide (requires sudo):

```bash
cmake --install buildDir
```

This will install:
- Shared library: `/usr/local/lib/libzyx.so`
- Headers: `/usr/local/include/zyx/`
- pkg-config file for easy integration

## Troubleshooting

### Conan Installation Fails

If Conan fails to install dependencies:

```bash
# Clear Conan cache
conan remove ".*" -f

# Retry installation
conan install . --output-folder=buildDir --build=missing
```

### Compiler Not Found

Ensure your C++ compiler supports C++20:

```bash
# Check GCC version
g++ --version

# Check Clang version
clang++ --version
```

### CMake Version Issues

```bash
cmake --version
pip3 install --upgrade conan
```
