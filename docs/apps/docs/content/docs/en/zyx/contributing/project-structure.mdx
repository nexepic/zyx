# Project Structure

ZYX is a C++20 embedded graph database. The current storage implementation is the native relocatable single-file format; the retired fixed-record `FileStorage`, `DataManager`, segment-chain, and external-WAL implementation is not present in the source tree and is not a compatibility path.

## Public Surface

- `include/zyx/zyx.hpp` is the C++ embedding API.
- `include/zyx/zyx_driver_abi.h` is the stable C-facing Driver ABI used by the Rust, Python, Node.js, and WASM bindings.
- `bindings/` contains the language adapters. Keep public ABI changes synchronized with their ownership and lifetime contracts.

## Native Runtime

| Area | Location | Responsibility |
|---|---|---|
| Core | `include/graph/core/`, `src/core/` | Database lifecycle, transactions, values, and public-operation coordination. |
| Storage boundary | `include/graph/storage/`, `src/storage/` | Logical graph interfaces, backend selection, portable I/O, storage format checks, and transaction overlays. |
| Native storage | `include/graph/storage/relocatable/`, `src/storage/relocatable/` | Relocatable pages, directories, COW publication, A/B Superblocks, integrity checks, maintenance, indexes, and large values. |
| Query engine | `include/graph/query/`, `src/query/` | Cypher parser, planning, optimization, logical read/mutation runtimes, procedures, and algorithms. |
| API and CLI | `src/api/`, `src/cli/` | C++ API implementation, Driver ABI, and command-line interface. |

`StorageIO`, `PreadHelper`, and `PwriteHelper` are the platform abstraction boundary for native file I/O. Do not add POSIX-only storage paths: macOS, Linux, and Windows must remain supported.

## Tests And Applications

- `tests/src/` contains unit and component tests; `tests/integration/` contains end-to-end coverage. CMake discovers `test_*.cpp` files and builds one `zyx_test_suite` executable.
- `apps/cli/` is the CLI. `apps/benchmark/`, `apps/compare_benchmark/`, and the calibration applications exercise current public/native paths.
- `benchmarks/graphdb-comparison/` contains the external comparison harness and its Python tests.

New tests must observe public behavior or a current native owner. Do not recreate tests for retired fixed-record implementation details.

## Build And Documentation

- `CMakeLists.txt` defines the project and targets; `cmake/SourceSets.cmake` allowlists current sources and rejects retired storage paths.
- `scripts/` contains build, test, binding, release, and parser-generation workflows.
- `docs/apps/docs/content/docs/en/` and `docs/apps/docs/content/docs/zh/` are the paired English and Chinese documentation roots. Update both when changing contributor-facing architecture or behavior.

Before submitting a storage change, run the relevant focused tests during development and `./scripts/run_tests.sh --quick` for final validation. See the [Native Single-File Storage Re-architecture Plan](/en/docs/zyx/architecture/native-single-file-storage-plan) for format and migration acceptance criteria.
