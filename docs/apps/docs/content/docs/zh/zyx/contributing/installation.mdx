# 安装指南

## 前置要求

在构建 ZYX 之前，请确保已安装以下依赖项：

### 必需工具

- **C++ 编译器**: 支持 C++20 的编译器
  - GCC 11+ 或 Clang 13+ (Linux)
  - Xcode 14+ (macOS)
  - MSVC 2022+ (Windows)
- **CMake**: 构建系统（版本 3.21+）
- **Conan**: 包管理器（版本 2.0+）
- **Ninja**: 构建后端

### 在 macOS 上安装

```bash
brew install cmake conan ninja
```

### 在 Linux 上安装 (Ubuntu/Debian)

```bash
sudo apt-get update
sudo apt-get install -y python3-pip g++ cmake ninja-build
pip3 install conan
```

### 在 Windows 上安装

```powershell
# 使用 Chocolatey
choco install cmake conan ninja

# 或使用 pip 安装 Conan
pip install conan
```

## 从源码构建

### 快速构建

构建和测试 ZYX 的最简单方法：

```bash
# 克隆仓库
git clone https://github.com/nexepic/zyx.git
cd zyx

# 安装依赖、构建并运行测试
./scripts/run_tests.sh
```

此脚本将：
1. 安装所有 Conan 依赖
2. 使用 CMake 配置构建
3. 编译项目
4. 运行所有测试并生成覆盖率报告

### 快速构建（跳过依赖安装）

如果您已经构建过且依赖已安装：

```bash
./scripts/run_tests.sh --quick
```

### 手动构建步骤

如需更多构建过程的控制：

```bash
# 安装 Conan 依赖
conan install . --output-folder=buildDir --build=missing --build="antlr4-cppruntime/*" -s build_type=Debug -s compiler.cppstd=20

# 配置 CMake 构建
cmake -S . -B buildDir -DCMAKE_TOOLCHAIN_FILE=buildDir/conan_toolchain.cmake -DCMAKE_BUILD_TYPE=Debug

# 编译
cmake --build buildDir
```

## 构建发布版本

用于生产环境构建：

```bash
./scripts/build_release.sh
```

这将在 `buildDir/release/` 中创建优化的发布版本。

## 验证安装

构建完成后，验证 CLI 工具是否可用：

```bash
./buildDir/zyx --help
```

您应该看到 ZYX CLI 的使用信息。

## 安装位置

构建输出位于：

- **CLI 工具**: `buildDir/zyx`
- **库**: `buildDir/libzyx.*`（公共库）和 `buildDir/libzyx_core.a`（内部静态库）
- **测试**: `buildDir/zyx_test_suite`

## 可选：系统级安装

要将 ZYX 安装到系统范围（需要 sudo）：

```bash
cmake --install buildDir
```

这将安装：
- 共享库：`/usr/local/lib/libzyx.so`
- 头文件：`/usr/local/include/zyx/`
- pkg-config 文件以便于集成

## 故障排除

### Conan 安装失败

如果 Conan 无法安装依赖：

```bash
# 清除 Conan 缓存
conan remove ".*" -f

# 重试安装
conan install . --output-folder=buildDir --build=missing
```

### 未找到编译器

确保您的 C++ 编译器支持 C++20：

```bash
# 检查 GCC 版本
g++ --version

# 检查 Clang 版本
clang++ --version
```

### CMake 版本问题

```bash
cmake --version
pip3 install --upgrade conan
```
